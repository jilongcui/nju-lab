# 第 20 章 图文引导 · 截图清单（给老师用）

> 用途：把学生最容易迷路的地方用**截图**讲清楚，插到实验页 `faq` / `references` 或章节正文里。
> 现状：本机装不上浏览器（Playwright 的浏览器二进制要外网），所以清单在这里，截图请在浏览器里截。

> 截图约定：**1920×1080 或 1440×900**，只截相关区域（用系统截图工具裁），文件名按下面编号，
> 存到 `docs/assets/ch20/`（新建目录，**不要**放进 `web/public`，避免进构建产物）。
