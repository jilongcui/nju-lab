# 空气质量估算 Skill（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 判据只要求"**测试集 MAE 比持久性基线低 ≥20%** + 说清选择"，所以换模型（RandomForest /
> 梯度提升）、换特征组合、换切分方式都能通过，你甚至可以做得比它更好。
>
> 它与你的起点 `skill-template/` 形态一致（同样的 `load_data` / `build_baseline` /
> `train_and_evaluate` / `main`），方便逐段对照。

## 能力边界

- 能处理：数值特征 + 单个数值目标（`pm25_next`）的回归数据，列名与 `data.csv` 一致
- 能处理：与"直接沿用上一小时"（持久性基线）的**对比评估**，报告 MAE 与 R²
- 不处理：类别特征编码、缺失值填充、时间序列滑窗构造（本实验数据已整理好）
- 不处理：目标列名不同的数据（`pm25_next` 写死在 `TARGET`）

## 方法（三步）

1. **读数据** —— `load_data`：看看有哪些列（数据字典见 `task.md`）
2. **算基线** —— `build_baseline`：先量化"现有做法"的成绩（`pm25_lag1` 直接当预测的 MAE）；
   没有基线，"比现有做法好"这句话就无从谈起
3. **训练 + 评估** —— `train_and_evaluate`：固定种子切分 → 训练 → 在**同一个测试集**上
   对比模型与基线 → 组装报告

产出结构（`output.json`）见 `task.md`；判据见 `judge.md`。
