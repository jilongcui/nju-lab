## 4. 踩坑记录（每条一行，平台按行计数）

1. 基线用测试集的平均单价算 → 基线成绩被"喂"得太准，达标线失去意义
2. 不加截距（`fit_intercept=False`）时比值回到 0.9 以上 —— 固定价值没被学出来
3. 残差要画出来才知道误差偏向；只看 MAE 看不出"大户型误差更大"
4. 图上写中文会变方框 —— 轴标签一律英文，中文只放在 `takeaway` 里

## 5. 结论（≥20 字：与基线比提升多少、难点在哪）

"平均单价 × 面积"把小户型报高、大户型报低，原因是总价里有一块固定价值；带截距的线性回归把这块学出来，MAE 降到基线的 0.66。
