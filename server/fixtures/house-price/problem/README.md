# 题目包：按面积估算房子总价（入门 · 回归）

> 这是本实验的**题目包** —— 一个很简单的真实需求（看面积报价）、判据、两批数据，
> 外加**一份示范实现**（`reference/`）供你对照学习。

## 这个实验要学什么

1. **回归在做什么**：用一个数值特征（面积）去估一个数值目标（总价）。
2. **基线（baseline）意识**："我的模型好不好"必须有参照物。本实验的参照物是
   **"全市平均单价 × 面积"** —— 中介真实会用的一种朴素做法。
3. **截距的意义**：为什么"平均单价 × 面积"会系统性偏差？因为总价里有一块与面积无关的固定价值，
   而**带截距的线性回归**正好能把它学出来。
4. **指标要能对业务说话**：为什么用 MAE（平均差多少万元）而不是 R²（方差解释比例）。
5. **可复现**：固定随机种子、写清切分，别人才能复核你的结论。

## 两批数据

| case | 规模 | 特点 | 参考水平（现有做法 → 参考实现） |
|---|---|---|---|
| case01 | 200 行 | 一线城市：单价高、房子大 | MAE 9.27 → **6.09**（比值 0.66） |
| case02 | 150 行 | 小城市：单价低、房子小 | MAE 9.19 → **5.96**（比值 0.65） |

> `expected.json` 里的数值**不是标准答案**，而是"参考水平"：判据用它核对你的
> `baseline.mae` 是否可信、并识别"可疑地过于好"的结果。你可以做得比参考实现更好，
> 只要说清是怎么做到的。

## 自测方法

CLI 约定：`train.py <case_dir> <output.json>`（`<case_dir>` 里要有 `data.csv`）。

```sh
# 两个 case 都跑一遍，看是否达标（比值 = metrics.mae / baseline.mae，要求 ≤ 0.78 / 0.80）
for c in cases/*/; do python3 <你的skill>/scripts/train.py "$c" /tmp/out.json; done
```

脚本末尾会打印 `[达标] / [未达标]` 与比值。判据的其余各项（结构、切分占比、`notes`）
请对照 `judge.md` 自己核一遍。

> 卡住了怎么办：先看 `reference/scripts/train.py` 里对应的那一段。
