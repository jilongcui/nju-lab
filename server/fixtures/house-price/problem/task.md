# 入门实验：按面积估算房子总价（回归）

## 业务背景

你是某房产中介门店的新同学。客户来看房，第一句常常是"这套多少万？"——
店里的老办法是：**看面积，乘一个全市平均单价，报个数**。

这个办法的问题很明显：**小户型会报高、大户型会报低**。因为总价里有一块"跟面积无关"的价值
（地段、装修、楼层……），摊到小面积上就显得单价高。所以真实成交价并不是严格的
"面积 × 单价"，而是更接近"**固定价值 + 单价 × 面积**"。

**现有做法（基线）**：全市平均单价 × 面积。它简单，但系统性偏差不小 ——
所以你的任务不是"跑个模型"，而是**比这个现有做法明显更准**。

## 你的任务

用工作目录里的 `data.csv` 做一个估价方案，产出 `output.json` 和你的图，达到三条要求：

1. **比现有做法明显更准**：在测试集上，平均绝对误差（MAE）**至少比"平均单价 × 面积"低 20%**。
2. **可复现**：切分与训练用固定随机种子；产出里写清 `n_train` / `n_test`
   （测试集占比 **20%~40%**，怎么切由你决定）。
3. **用图把判断讲清楚**：看数据时画一张图、评估结果时画一张图，并给每张图写一句结论
   （写进 `output.json` 的 `figures` 字段）。

> 这是**入门实验**：只有一个特征（面积）。模型由**你自己决定**
> （线性回归、KNN 回归、决策树都可以），选一个你能讲清楚的即可。

## 实验流程（六步，每一步都要走完）

| 步 | 做什么 | 产出/落点 |
|---|---|---|
| ① **看清需求** | 报多了客户不来看、报少了业主不签；目标是比"平均单价 × 面积"更准 | 心里有数 |
| ② **看一眼数据 + 画图** | 面积与总价是什么关系？总价怎么分布？有没有"单价随面积变化"的迹象？**画一张散点图** | `figures/` 里第 1 张图 |
| ③ **定基线** | 现有做法（平均单价 × 面积）的成绩：**平均单价只用训练集估**，在同一个测试集上算 MAE | 报告的 `baseline` |
| ④ **训练模型** | 选一个模型，固定种子切分后训练 | 报告的 `model` / `metrics` |
| ⑤ **评估 + 画图** | 算 MAE / R²，**画一张预测 vs 实际的图**看误差偏向哪一边 | `figures/` 里第 2 张图 |
| ⑥ **写结论** | 每张图一句结论（`figures[].takeaway`）+ 整体判断（`notes`：比基线好多少、还有什么不足） | 报告的 `figures` / `notes` |

> 图用 `matplotlib` 画（镜像已预装），存到工作目录的 `figures/` 下，
> 例如 `plt.savefig("figures/data_overview.png", dpi=110)`。
>
> ⚠️ 图里的**标题与坐标轴标签用英文**（如 `area (m2)`）：运行环境里没有中文字体，
> 中文会渲染成方框。中文解释写在 `takeaway` 和 `notes` 里（那些是给人读的）。

## 数据字典（`data.csv`）

| 列 | 含义 |
|---|---|
| `area_m2` | 建筑面积（m²） |
| `total_price_wan` | **目标**：成交总价（万元） |

> 数据是固定种子合成的教学数据，规律符合常识：**面积越大总价越高**，
> 但总价里有一块固定价值（地段/装修），所以"单价"在小户型上更高。
> 同一面积的房子价格还有波动 —— 那是面积之外的因素，任何只用面积的模型都消不掉。

## 交付格式

**`output.json`**（写在工作目录下）：

```json
{
  "model": "你最终选择的模型名称（例如 LinearRegression / KNN / DecisionTree）",
  "n_train": 150,
  "n_test": 50,
  "metrics": { "mae": 6.1, "r2": 0.98 },
  "baseline": { "name": "average_price_per_m2", "mae": 9.3 },
  "figures": [
    { "path": "figures/data_overview.png", "takeaway": "面积与总价近似线性；小户型单价更高，说明有一块固定价值。" },
    { "path": "figures/evaluation.png", "takeaway": "预测点贴着 y=x，残差大致以 0 为中心；大户型误差略大。" }
  ],
  "notes": "先画散点确认面积与总价近似线性、小户型单价更高，所以用带截距的线性回归；测试集 MAE 6.1，比「平均单价 × 面积」的现有做法（9.3）低约 34%。不足：同一面积的价差靠面积解释不了。"
}
```

- `metrics` 至少要有 `mae`（`r2` 可选，推荐给）。
- `baseline.mae` 必须是你**自己算出来的**：平均单价**只用训练集**估计，
  再在**同一个测试集**上算"单价 × 面积"的 MAE。（判据会核对它是否可信。）
- `figures` 至少两张：一张"看数据"（②）、一张"评估结果"（⑤），每张都要有 `path` 与一句 `takeaway`。
- 不需要和任何"标准答案"的数值一致 —— 达标看的是"是否真的比基线低 20%"。

## 怎么算完成

1. 写一个能跑的方案（推荐做成 Skill 里的一段脚本），能对任意一份同结构 `data.csv`
   产出 `output.json` 与两张图。
2. 在 `cases/case01` 与 `cases/case02`（另一个城市的数据）上都达标 —— 判据对两个 case 各判一次。
3. 把结论与踩过的坑写进 `SKILL.md` 的「实测档案」。

判据全文见 `judge.md`；怎么自测、包内还有什么，见 `README.md`。
