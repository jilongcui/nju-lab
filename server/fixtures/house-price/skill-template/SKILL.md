# 房价估算 Skill（你的方案）

> **这是入门实验，重点不是"用多强的模型"，而是把一次完整的小分析走完**：
> 看一眼数据 → 定基线 → 训练 → 评估 → 写结论。
> 模型由你自己决定（线性回归、KNN、决策树都行），达标看的是
> "**MAE 比现有做法低 20%** + 能不能用图说清判断"。

## 实验材料（都在题目包 `problem/` 里，领取后工作区就有）

| 材料 | 作用 |
|---|---|
| `task.md` | 业务背景 + 三条要求 + 数据字典 + 交付格式 |
| `judge.md` | 判据：达标线怎么算、哪些项会被核对 |
| `reference/` | 一份**示范实现** —— 先读它，再写你自己的（它不是标准答案） |
| `cases/case01`、`cases/case02` | 两批数据（两个城市），自测用 |

**实验流程（六步，与 `task.md` 一致 —— 每一步都要走完）**：

| 步 | 做什么 | 落在哪 |
|---|---|---|
| ① 看清需求 | 比"平均单价 × 面积"更准 | 心里有数 |
| ② **看一眼数据 + 画图** | 面积与总价的关系、有没有"单价随面积变化" | `figures/` 里第 1 张图 |
| ③ 定基线 | 现有做法：平均单价（只用训练集估）× 面积 | 报告的 `baseline` |
| ④ **训练模型** | 选一个能讲清楚的模型训练 | 报告的 `model` / `metrics` |
| ⑤ **评估 + 画图** | 算 MAE / R²，画预测 vs 实际看误差偏向 | `figures/` 里第 2 张图 |
| ⑥ **写结论** | 每张图一句结论 + 整体判断（好多少、不足） | 报告的 `figures` / `notes` |

材料配合：`task.md`（需求 + 流程）→ 读 `reference/`（一份**走完这六步**的示范，含它画的两张图与各自结论）→ 回 `scripts/train.py` 走自己的六步 → 两个 case 都跑 → 补全下面的能力边界与实测档案 → 提交。

## 要做的决策（本实验的重点）

1. **模型**：为什么选它？"平均单价 × 面积"和"线性回归"到底差在哪（提示：截距）？
2. **基线**：现有做法怎么算？为什么平均单价只能用**训练集**估？
3. **评估**：MAE 和 R² 分别告诉中介什么？残差图能看出什么？
4. **不足**：只用面积，哪些误差是消不掉的？在 `notes` 里如实写。

## 自测

```sh
for c in cases/*/; do
  python3 scripts/train.py "$c" /tmp/out.json
done
```
