- 自测时间：2026-10-10（参考实现复验 2/2 通过）

- 关键数字：
  - case01：报告单 15 行 → 13 项（12 可判定 + 1 表外 `BIL-T`），丢弃 1 非法 + 1 重复；
    危急值 3 个（`K` 6.2、`PLT` 28、`WBC` 1.2）
  - case02：报告单 19 行 → 16 项（15 可判定 + 1 表外 `FERR`），丢弃 1 非法 + 2 重复；

- 踩坑记录（pitfalls）：
  - **两条边界口径方向相反**：`flag` 严格不等（等于参考上限算正常），危急值闭区间（等于危急阈值就报警）
    —— 一开始两条都写成同一方向，`LDL` 3.4 与 `K` 6.2 全判错了
  - 全角数字必须按 NFKC 转半角再 `float()`：`６．４` 直接解析会失败，整行被当成非法值丢掉
  - 去重口径是"保留**首次**出现"：`case02` 里 `K` 先出现 3.5、后面又出现 7.1（危急值），
    若按"取更严重的"就会多报一个危急值
  - `item` 排序用 `sorted()`（ASCII 序）：`HBA1C` / `HGB` 这类全大写项目名不会有歧义，
    但如果混入小写就会排到后面 —— 列表顺序也是断言要比对的一部分
