检验报告与临床病历的完整写作指南综述

一份完整的检验报告通常包含患者信息、标本类型、检测方法、结果、参考区间与备注。写作时要区分「结果」「解释」与「建议」三层：结果是仪器测得的数值，解释是结合参考区间与病史的理解，建议是下一步动作。不同医院的方法学与参考区间可能不同，跨院比较前要确认可比性。备注里常见「复查」「溶血」「脂血」等标注，这些标注会影响结果的解读，应当在报告里如实转述而不是省略。危急值要按制度通报并登记，登记内容包括项目、结果、通报时间、接收人与复查情况，未闭环的危急值要在交接班时再次核对。报告还要写明采样时间与检测时间，因为部分指标在样本放置过久后会漂移，报告若缺少这些信息就无法复核。
