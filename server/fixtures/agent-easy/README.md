# agent-easy —— 入门实验：写一个四环随访助手（智能体 · 容易）

> 对应课程章节：**智能体：定义、框架与常用选择**（动手实践：亲手跑通四环，再指出哪一环该换成模型）。
> 难度 **easy**：全部规则实现，只用 Python 标准库 + `matplotlib`，不装任何东西、不联网。

## 场景与数据

- 应用：社区卫生站的糖尿病随访助手 —— 听懂一句"帮我看下 P001 这次要不要复查"，走完四环。
- 数据：`problem/cases/case01`（5 患者 / 6 请求）、`case02`（4 患者 / 5 请求），
  每个 case 三个文件：`patients.csv`、`requests.txt`、`memory_seed.json`；
  `case02` 的种子里已有 P001 的接触记录，用来验证"消息读的是处理本条之前的记忆"。
- 造题：`tools/gen_cases.py`（固定数据、可重跑；**不下发**）。

## 判据设计要点

1. **口径钉死 → 逐字段可比**：六条决策规则的**优先级**写进 `task.md`，`perceive` / `decisions` /
   `messages` / `memory_after` / `counts` 全部与 `expected.json` 逐字段比对（消息模板逐字）。
2. **两条边界单独判**：`invalid_request` / `unknown_patient` **不写记忆**（比对 `memory_after` 的键集）；
   case02 第二条 P001 的"上次联系"必须是第一条写下的 `2026-10-01`（区分"跨请求生效"与"只读种子"）。
3. **防退化**：偷懒解"所有请求都回 none"会在 `decisions` / `counts` 上被判据抓住（case01 有 4 条判错）。
4. **不给代码答案**：`skill-template/scripts/solve.py` 只留 TODO；`problem/reference/` 是示范，随题包下发。

## 项目字段文案（建项目时用）

- **title**：入门实验：写一个四环随访助手（智能体 · 容易）
- **difficulty**：`easy`
- **content**（学生详情页首屏；不写"你的任务"）：
  社区卫生站的护士每天要做三件事：看数据、做判断、把这次沟通记下来。现在把它们交给一个规则版智能体：
  听懂一句"P001 这次要不要复查"，自己走完感知、决策、行动、记忆四环，最后交一份结构化结果。
- **objectives**：
  1. 能说清"感知 / 决策 / 行动 / 记忆"四环各自负责什么、数据怎么在四环之间流动；
  2. 能把一条业务规则表（六条、有优先级）实现成确定性的代码判断；
  3. 知道记忆为什么要跨请求生效、以及"哪一类请求不该写记忆"。
- **background**（每条 = 概念 + 一句人话解释）：
  - **四环（感知—决策—行动—记忆）**：智能体的最小闭环；缺感知就没数据、缺行动就只是空谈、缺记忆每次从零开始。
  - **规则版 vs 智能体版**：规则版所有"聪明"写在一张规则表里；智能体版把走哪条路交给模型，但口径仍要写死。
  - **优先级**：规则不是并列的 —— "先看患者号是否有效"必须排在"看指标"前面，顺序错了结论就错。
  - **记忆边界**：只有正常决策才写记忆；无效请求与未知患者写进去，会让记忆表变脏。
  - **可复现**：今天固定 `2026-10-01`，天数用日期相减 —— 不写死就每次结果不同。
- **description**：
  1. 读实验内容与 `task.md` 的六条规则，确认优先级与消息模板；
  2. 先跑 `case01`：补 `perceive` → `decide` → `act` → 写记忆，四环逐个跑通；
  3. 再跑 `case02`，重点看第二条 P001 的"上次联系"有没有变成 `2026-10-01`；
  4. 画各类动作条数柱状图（轴标签英文）；
  5. 填 `report.md`（六节，含踩坑 ≥1 条）。

## 实测记录（出题时）

- 参考实现两个 case 全对：`perceive` / `decisions` / `messages` / `memory_after` / `counts` 与 `expected.json` 一致；
- case01：6 请求，动作分布 urgent 1 / recall 2 / annual 1 / none 1 / unknown_patient 1 / invalid_request 1，记忆 3 条；
- case02：5 请求，动作分布 urgent 1 / recall 2 / none 1 / unknown_patient 1，记忆 3 条，第二条 P001 读到 `2026-10-01`。
