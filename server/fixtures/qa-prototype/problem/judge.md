评分细则（**综合实践：分子医学知识问答原型**）

⚠️ 每个问题的**路由**、`key_facts`、出处 `sources` 的形态组合、Q04 的三元组链，都已经由
`task.md` 的口径钉死，因此是**确定的**。这些已由平台用**确定性断言**判定（见 `manifest.json`
的 `assertions`）：字段完整、题目数量与顺序、每题 `route`、每题 `key_facts`、`sources` 的
`kind` 组合与 `ref` 非空、Q04 的路径、`route_counts`、四种形态是否都用上、`confidence` 范围、
`answer` 长度、图与 `notes` 长度。断言未通过的结果**不会交给你判**，你不必重算这些。

你只需要判断以下**语义**问题（任一项不成立 → 不通过）：

1. **是否说清了"为什么这一题走这条路"**：需要能看出判断依据 —— 精确数字/按条件筛 → SQL；
   原文里**直接出现**指定术语 → 关键词；问法里没有那些原词、要按"意思相近"找 → 相似度；
   答案是一串关系（"为什么""推理链"）→ 图谱多跳。以下情况**不通过**：只说"用了图谱检索"、
   "综合多种方法"这类空话；把"两跳组合题"说成单一路径；路由与理由互相矛盾
   （例如说"因为要精确数字所以走了向量检索"）。
2. **出处是否真的能追溯、且与答案自洽**：`sources[].ref` 指向的对象必须与该题 `key_facts` 对得上
   （表名:主键 对应同一个试验号/适应证；段落号对应 `passage_ids`；`edges:` 起止节点对应路径两端）。
   出现"表名与主键不匹配""出处指向的另一条数据"→ 不通过。**只看报告内部自洽性**，
   不需要你去核对原始数据文件。
3. **有没有把"检索结果"直接当"结论"**：这是本章点名的坑。答案应当写成
   "数据/段落/图谱路径显示……"这种**有依据的陈述**；出现越界断言 —— 例如
   "这是标准治疗方案，必须使用""患者应该立即用药""可以确诊"这类**超出给定数据**的结论
   → 不通过。（描述机制、说明依据属于正常，不算越界。）
4. **`notes` 是否讲清了形态分工与局限**：要说清四种形态各解决了什么（精确事实 / 原文出处 /
   换了说法的近似匹配 / 关系链与可解释性），并给出**至少一条真实的局限**
   （例如语料规模小、字符 2-gram 只是"近似语义"而不是真正的向量模型、图谱缺关系时没有兜底、
   没接大模型做生成）。只复述题干、只堆字段名、写成运行日志 → 不通过。
5. **`figures[].takeaway` 是否与 `route_counts` 自洽**（看图说话，允许四舍五入）；
   只写"我画了一张柱状图"或数字与 `route_counts` 矛盾 → 不通过。

判定口径：
- 键序、缩进、空白、小数位、`confidence` 的具体取值都不扣分。路由与事实**由断言负责**；
  你只管「理由是否站得住」「出处是否自洽」「有没有越界」。
- `score` = 上述语义项的达成程度（0~1）；任一项不成立时 score 不超过 0.5。
- rationale 用中文、**一句话（≤60 字）**说清结论；不通过时指出具体是哪一项。
