# 分子医学知识问答原型（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 判据只看"走对了路 + 关键事实对 + 出处带出来 + 说得清"，所以函数怎么切、图怎么画都随你；
> 换一种写法只要口径一致就能通过。

## 能力边界

- 能处理：`genes.csv` / `variants.csv` / `drugs.csv` / `trials.csv` / `passages.csv` / `edges.csv` /
  `questions.csv` 这套固定结构的输入
- 能处理：结构化事实的精确查询与筛选（分期、适应证这类条件）、按术语共现定位段落、
  按字符 2-gram 相似度找"换了说法"的段落、有向图的多跳最短路径
- 能处理：两跳组合（先查图谱拿适应证，再查关系库拿试验数据）
- 不处理：**真正的语义检索**（环境里没有向量模型，只能用字符 2-gram 近似）
- 不处理：图谱里不存在的关系（没有兜底回落，只会如实说"查不到"）
- 不处理：由大模型生成自然语言答案（课程后面的 RAG 章节再补这一环）
- 不处理：任何诊疗建议 —— 答案只描述"数据/段落/图谱显示了什么"

## 方法（六步 —— 与 `task.md` 的流程一致）

1. **看清需求** —— 五个问题分别要"精确数字 / 原文段落 / 意思相近的段落 / 推理链 / 两跳组合"
2. **摸清材料** —— `load_all`：五张表 + 段落 + 关系边，各自的主键与方向
3. **搭四个入口** —— `build_sql`（内存 SQLite）/ `keyword_passages` / `rank_passages_by_similarity` /
   `shortest_path` + `neighbors`
4. **逐题路由** —— `answer_question`：选路 → 取事实 → 把出处写进 `sources`
5. **汇总与画图** —— `route_counts` + `plot_routes`
6. **写结论** —— `compose_notes`（形态分工 + "检索结果不是结论"这条坑 + 局限）

产出结构（`output.json`）见 `task.md`；判据见 `judge.md`。

## 为什么每个答案都要带出处（本章的教学点）

- **检索结果只是线索，不是结论**：把"检索到的段落"直接当成"正确答案"说出去，正是本章点名的坑；
  出处（`trials:T-102` / `passages:P-01` / `edges:BRCA1->olaparib`）让结论**可核查**；
- **四种形态各管一段**：关系库管精确与统计、文本管原文出处、相似度管"换了说法"的近似匹配、
  图谱管关系链与可解释性 —— 没有任何一种能单独回答全部问题；
- **多跳要给出完整链**：图谱的价值不只是"答案对"，而是**每一步都能核查**（路径写出来）。

## 实测档案

- 自测时间：2026-10-10（参考实现复验 2/2 通过）
- 用例通过率：2/2
- 关键数字（两个 case 一致）：
  - 路由分布：`sql` 1 题、`keyword` 1 题、`vector` 1 题、`graph` 2 题
  - Q01：`T-102` / III 期 / 客观缓解率 **62.4%**（注意同药还有一条 II 期 `T-105`，按分期筛）
  - Q02：`P-01`（唯一同时字面出现 PARP / BRCA / 卵巢癌的段落）
  - Q03：`P-03`（字符 2-gram 余弦最高的一段：同源重组修复缺陷 → 合成致死）
  - Q04：3 跳链 `BRCA1|loss_of_function|同源重组修复缺陷` → `同源重组修复缺陷|synthetic_lethal_with|PARP抑制剂`
    → `PARP抑制剂|includes|olaparib`；类别药物 `niraparib` / `olaparib` / `talazoparib`
  - Q05：适应证 `铂敏感复发卵巢癌` + `T-101` / 客观缓解率 **45.0%**（图谱 + SQL 两跳）
- 踩坑记录（pitfalls）：
  - **按药名查试验会选错**：`olaparib` 有 III 期与 II 期两条，题意要 III 期 —— 少了 `phase` 条件就取错行
  - **关键词与相似度是两条路**：Q02 靠"三个术语字面共现"（唯一命中 `P-01`），Q03 的问法里
    没有那段的关键词，只能按相似度找 —— 用错方法就会找不到或找到错的那段
  - **边是有向的**：`BRCA1 → 卵巢癌` 不代表能从卵巢癌回到 BRCA1，BFS 必须按 `head → tail` 走
  - **同长度多条路径要定序**：取边序列 ASCII 升序最小的那条，否则结果会抖
  - **别把检索结果当结论**：`answer` 里要写"数据/图谱路径显示……"，不能写成诊疗建议
