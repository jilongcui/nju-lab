# 深度学习入门实验二：按练习情况估算期末成绩（回归 · easy）

**定位（easy 档）**：第 3 章《深度学习基本原理和实践》的**入门**实验 —— 用一层隐藏层的小网络
学一条**饱和曲线**，让"为什么需要非线性模型"变成可量化的对比：线性回归比值约 0.57~0.60，
小网络 0.32 / 0.45，达标线卡在 0.55。与同章 medium 实验（训练诊断 / 卷积 / 序列）**不重复**：
那三个是完整应用 + 复杂结构，本实验是"先把一轮训练跑通、看懂非线性"。

## 场景与数据

- 应用：辅导班按每周练习时长与出勤率估算期末成绩
- 对应章节：课程第 3 章《深度学习基本原理和实践》（神经网络回归的第一个例子）
- 数据：固定种子合成（`tools/gen_data.py` 可重跑，逐字节相同）

| 列 | 含义 |
|---|---|
| `weekly_hours` | 每周练习时长（小时） |
| `attendance_rate` | 出勤率（0.5~1.0） |
| `final_score` | 目标：期末成绩（0~100 分） |

| case | 规模 | 特点 |
|---|---|---|
| case01 | 240 行 | 正常一个班（噪声 σ=5 分） |
| case02 | 180 行 | 另一个班：记录更粗（σ=6 分） |

**数据规律**：`成绩 ≈ 100 × (1 − e^(−0.16 × 练习时长 − 0.8 × 出勤率)) + 噪声` ——
典型饱和曲线，前 10 小时涨得最快、20 小时以后基本到顶。

## 判据设计要点

1. **"真的训练了"是硬性条件**：`training.history` ≥5 轮、每轮有 `train_loss`、
   最后一轮 < 第一轮 —— 只报一个 MAE 混不过去。
2. **达标线卡在"线性 vs 非线性"之间**：`mae ≤ 0.55 × baseline.mae`。
   平均分基线比值 1.0、双特征线性回归约 0.57~0.60（**过不了**）、两层 MLP 0.32~0.45（能过）。
3. **基线可信**：核对 `baseline.mae` 与参考值相差 ≤15%，防止虚报基线。
4. **切分覆盖 + 占比**：`n_train + n_test === n_rows`、测试集占比 20%~40%。
5. **期望值不是满分**：参考实现 3.16 / 4.72（MAE），离噪声下界仍有距离 —— 留出改进空间。
6. **图要说人话**：看数据（两个散点）、训练曲线、预测-实际 + 残差，语义上要求
   "说出关系是不是直线、损失怎么变、哪一段误差大"（judge 判，不写数字）。

## 出题时的实测依据（2026-10-17）

| 指标 | case01 | case02 |
|---|---|---|
| 一律报平均分（基线）MAE | 9.8159 | 10.5373 |
| 两特征线性回归 MAE / 比值 | 5.881 / 0.599 | 5.983 / 0.568 |
| 参考实现（两层 MLP）MAE / 比值 | **3.1628 / 0.32** | **4.7158 / 0.45** |
| 训练损失（第 1 轮 → 第 200 轮） | 0.81 → 0.10 | 0.83 → 0.11 |
| 达标线（比值上限） | 0.55 | 0.55 |

- **踩过的坑**：最初只标准化输入、不标准化目标，60 轮训练直接不收敛（MAE 12.9 > 基线 9.8），
  训练损失从 7671 只降到 274；目标也标准化之后 200 轮内收敛到 0.10。
  这个坑写进了 `problem/README.md` 的导学提示与参考实现的「实测档案」。
- 达标线是"量出来"的：先把线性回归跑了一遍（0.599 / 0.568），才把线定在 0.55。
- `expected.json` 由参考实现在**与复验同一个镜像**（`nju-lab-verify:0.2.0-rc.2-pkg6`）里生成。

## 项目字段文案（建项目时用）

- **title**：入门实验：按练习情况估算期末成绩（回归 · 神经网络 · 容易）
- **difficulty**：`easy`
- **content**（学生详情页首屏 = task.md 的「业务背景 + 你的任务」）：

  > 辅导班想在期末前按"每周练习时长 + 出勤率"估算每个学生的成绩，好提前排辅导。
  > 老师的老办法是一律报平均分，对练得多/练得少的学生都不准。你的任务：训练一个小神经网络，
  > 在测试集上 MAE 至少比"一律报平均分"低 45%；记下逐轮训练损失（证明真的训练了）；
  > 看数据画一张图、训练与评估再各画一张，每张图写一句结论。

- **objectives**（学完能讲清什么）：
  1. 回归任务里"基线"是什么、为什么先算"一律报平均分"；
  2. 特征与目标不是直线关系时，线性模型为什么会系统性偏差；
  3. 训练损失曲线说明什么、标准化为什么影响收敛。
- **background**（每条 = 概念 + 一句人话解释；出现术语当场解释，容易档不写公式）：

  - **数据**：每个学生两个数（每周练习时长、出勤率）和一个结果（期末成绩）。关系不是直线：
    练得越多分越高，但越往后每多练一小时的提升越小——这是一条饱和曲线。
  - **为什么线性模型会偏**：一条直线只能持续上升或持续下降，拟合不了「先陡后平」，中段必然系统性
    偏差。不建模、一律报平均分，就是这次的对照下限。
  - **标准化**：把每个特征（和目标）减去均值、再除以标准差，统一成「平均 0、波动 1」的尺度。
    练习时长是小时、成绩是分数，量纲差得远；不统一尺度时梯度下降会被大数值特征带偏，收敛很慢
    甚至不收敛（本实验里目标不标准化时 60 轮都降不下去）。
  - **隐藏层与 ReLU**：隐藏层先把两个特征组合成若干中间量，**ReLU**（负数变 0、正数保留）把折线
    关系接起来——这样网络才能表达「先陡后平」的曲线。
  - **训练在做什么**：**MSELoss** 把「预测与真实差值的平方」取平均，值越小越好；梯度下降按它调整
    参数，逐轮记录损失就能看出是否收敛（曲线走平即差不多收敛）。
  - **MAE 与 R²**：MAE 是「平均差多少分」，业务能直接读；R² 是「模型解释了成绩波动的百分之多少」。
    饱和曲线下 R² 可能不低、个别区段 MAE 仍大，两个都要看。
- **description**（导学步骤，≤8 步；不提 `task.md`，最后一步是生成报告）：
  1. 读实验内容与本节的达标要求，确认 MAE 相对基线的达标比，以及必须记录逐轮训练损失；
  2. 画两个特征与成绩的散点图，说明关系为什么是饱和曲线、不是直线；
  3. 算基线：一律报平均分算 MAE，写进 `baseline`；
  4. 标准化输入与目标，搭小网络训练并逐轮记录损失；
  5. 算测试集 MAE 与 R²，对照达标比；
  6. 画训练损失曲线与预测-实际图，说明哪一区段误差大；
  7. 用题目包里的两个 case 各跑一遍，并对照判据自查——图有没有说清、模型与训练历史是否自洽、基线定义对不对；
  8. 生成实验报告 `report.md`：数字由平台从各 case 的 `output.json` 自动填入，你只补结论与踩坑，确认后提交。
- **references**：`torch.nn` 的 `Linear`/`ReLU`/`MSELoss` 文档；
  `sklearn.metrics.mean_absolute_error`；`problem/reference/scripts/train.py`（示范实现）。
- **faq**：为什么损失几乎不降？（目标没标准化，或学习率太小）；为什么线性回归过不了？
  （饱和曲线，直线在中段必然偏）；训练多少轮合适？（看曲线，平了就行；本实验约 100~200 轮）。
