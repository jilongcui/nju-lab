# 成绩估算 Skill（你的方案）

> **这是入门实验，重点是"看懂神经网络怎么学一条曲线"**：输入 → 网络 → 损失 → 反向传播调参数。
> 网络结构、优化器、轮数都由你决定，达标看的是
> "**MAE 比一律报平均分低 45%** + **真的训练了（损失在降）** + 能不能用图说清"。

## 实验材料（都在题目包 `problem/` 里，领取后工作区就有）

| 材料 | 作用 |
|---|---|
| `task.md` | 业务背景 + 三条要求 + 数据字典 + 交付格式 |
| `judge.md` | 判据：达标线、训练历史的核对方式 |
| `reference/` | 一份**示范实现** —— 先读它，再写你自己的（它不是标准答案） |
| `cases/case01`、`cases/case02` | 两批数据，自测用 |

**实验流程（六步，与 `task.md` 一致 —— 每一步都要走完）**：

| 步 | 做什么 | 落在哪 |
|---|---|---|
| ① 看清需求 | 按人估算、比"一律报平均分"准 45%；并且真的训练了 | 心里有数 |
| ② **看一眼数据 + 画图** | 关系是不是直线？饱和在哪？ | `figures/` 里第 1 张图 |
| ③ 定基线 | 一律报训练集平均分 | 报告的 `baseline` |
| ④ **训练模型** | 小网络 + 逐轮记录训练损失 | 报告的 `training.history` |
| ⑤ **评估 + 画图** | 算 MAE / R²，画训练曲线与预测-实际 | `figures/` 里第 2、3 张图 |
| ⑥ **写结论** | 每张图一句结论 + 整体判断（损失怎么变、哪儿误差大） | 报告的 `figures` / `notes` |

材料配合：`task.md`（需求 + 流程）→ 读 `reference/`（一份**走完这六步**的示范，含三张图与各自结论）→ 回 `scripts/train.py` 走自己的六步 → 两个 case 都跑 → 补全能力边界，并把自测记录写进同级的 `dossier.md` → 提交。

## 要做的决策（本实验的重点）

1. **网络结构**：隐藏层要几个单元？为什么？
2. **标准化**：输入和目标要不要都标准化？不做会怎样（看损失曲线）？
3. **基线**：现有做法怎么算？为什么"一律报平均分"在这个数据上误差不小？
4. **评估**：MAE 和 R² 分别告诉老师什么？残差图能看出哪一段估得差？

  python3 scripts/train.py "$c" /tmp/out.json

> 再回来改自己的实现。
