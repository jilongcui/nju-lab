评分细则（**入门实验：神经网络回归，达标判定**）

⚠️ 本任务的网络结构、优化器、轮数由学生自选，**输出数值不要求等于参考水平**
（`expected.json` 里给的是"参考水平"，不是标准答案）。

**硬性条件已由平台用确定性断言判定**（见 `manifest.json` 的 `assertions`）：字段完整、
图说明齐全、指标为正、切分覆盖全部样本、测试集占比 20%~40%、基线报告可信（与参考值相差 ≤15%）、
**达标线 `metrics.mae ≤ 0.55 × baseline.mae`**、**逐轮损失 ≥5 轮且最后一轮低于第一轮**、
`notes` ≥20 字。断言未通过的结果**不会交给你判**，你不必重算这些数值。

你只需要判断以下**语义**问题（任一项不成立 → 不通过）：

1. **`figures` 与 `notes` 是否"看图说话"**：`takeaway` 要与图的类型相称 ——
   看数据那张要能说出"关系是不是直线、饱和/递减在哪"；训练曲线那张要说出"损失怎么变"；
   预测-实际那张要说出"误差偏向哪一段"。三张图互相复述、明显是套话、
   或与 `model` / `metrics` / `training` 矛盾 → 不通过。
2. **`model` 与 `training` 是否自洽**：例如 `model` 写着"两层 MLP"却报告 `epochs` 与
   `history` 长度不一致；或 `training.history` 里的损失明显不是这一轮训练产生的
   （例如所有值都相同、或损失反而上升却声称"训练收敛"）→ 不通过。
3. **是否可疑地过于好**：若 `metrics.mae` 低于参考水平 `reference.mae` 的一半，
   且 `notes` 未给出可核对的解释（怎么做到的）→ 判为可疑（疑似用测试集调参或数据泄漏）→ 不通过。
4. **`baseline` 的定义是否正确**：必须对应"一律报训练集平均分"这类朴素做法。
   若学生把"另一个训练好的模型"当基线（自欺欺人地拉低参照）→ 不通过。

判定口径：
- 键序、缩进、空白、小数位差异不扣分。
- `score` = 上述语义项的达成程度（0~1）；任一项不成立时 score 不超过 0.5。
- rationale 用中文、**一句话（≤60 字）**说清结论；不通过时指出具体是哪一项。
