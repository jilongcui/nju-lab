# 题目包：按练习情况估算期末成绩（入门 · 神经网络回归）

> 这是本实验的**题目包** —— 一个真实感很强的小需求（提前发现要补课的学生）、判据、两批数据，
> 外加**一份示范实现**（`reference/`）供你对照学习。

## 这个实验要学什么

1. **回归 + 非线性**：特征与目标不是直线关系时，直线拟合会系统性偏差 ——
   一层隐藏层的小网络就能把"饱和曲线"学出来。
2. **"真的训练了"长什么样**：看得到逐轮损失下降（`training.history`）。
3. **基线意识**：先问"不建模能做到多少"（一律报平均分），再看模型值不值。
4. **标准化的作用**：输入和目标的尺度差太多时，训练会变慢甚至不收敛（这是本实验最常踩的坑）。
5. **误差要看分布**：MAE 告诉你"平均差几分"，残差图告诉你"哪一段估得最差"。

## 实验流程（六步）

`task.md` 里写了完整流程（① 看清需求 → ② 看一眼数据并画图 → ③ 定基线 → ④ 训练网络 →
⑤ 评估并画图 → ⑥ 写结论），`reference/scripts/train.py` 是一份**把这六步都走完**的示范 ——
照着走一遍，再换成你自己的做法。

## 两批数据

| case | 规模 | 特点 | 参考水平（基线 → 参考实现） |
|---|---|---|---|
| case01 | 240 行 | 正常一个班（噪声 σ=5 分） | MAE 9.82 → **3.16**（比值 0.32） |
| case02 | 180 行 | 另一个班：记录更粗（σ=6 分） | MAE 10.54 → **4.72**（比值 0.45） |

> `expected.json` 里的数值**不是标准答案**，而是"参考水平"：判据用它核对你的
> `baseline.mae` 是否可信、并识别"可疑地过于好"的结果。

## 为什么要用"会拐弯"的模型（出题依据）

同一份数据上量出来的对比（测试集，`random_state=42`）：

| 做法 | case01 比值 | case02 比值 |
|---|---|---|
| 一律报平均分（基线） | 1.00 | 1.00 |
| 两个特征 + 线性回归 | 0.599 | 0.568 |
| 两个特征 + 两层 MLP（参考实现） | **0.32** | **0.45** |

达标线卡在 0.55：**线性回归过不了**（饱和曲线学不像），换成一层隐藏层的小网络就能过。
这正是本章要讲的"非线性"的直观意义。

## 自测方法

CLI 约定：`train.py <case_dir> <output.json>`（`<case_dir>` 里要有 `data.csv`）。

```sh
# 两个 case 都跑一遍，看是否达标（比值 = metrics.mae / baseline.mae，要求 ≤ 0.55）
for c in cases/*/; do python3 <你的skill>/scripts/train.py "$c" /tmp/out.json; done
```

脚本末尾会打印 `[达标] / [未达标]` 与比值。判据的其余各项（训练历史、切分占比、`notes`）
请对照 `judge.md` 自己核一遍。

> 卡住了怎么办：先看 `reference/scripts/train.py` 里 `train_model` 的两处标准化，
> 再检查你的训练循环（`zero_grad → forward → loss → backward → step`）。
