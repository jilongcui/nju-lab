评分细则（逐字段核对实际产出 output.json 与期望产出 expected.json）：

1. 只允许出现四个键：`total_revenue`、`by_region`、`top_product`、`row_count`。
   - 键名拼写不同、多键、少键、或把数值写成字符串 → 不通过。
2. `total_revenue`：与期望值的绝对差 ≤ 0.01 视为一致。
3. `by_region`：键集合必须与期望完全一致（多一个地区、少一个地区都不行）；
   每个地区的值与该地区的期望值绝对差 ≤ 0.01。
4. `top_product`：必须与期望字符串完全一致（大小写、拼写都要一致）。
5. `row_count`：必须与期望完全相等（整数）。

判定口径：
- JSON 的键序、缩进、空白、换行差异不扣分。
- 数值只要在容差内即视为一致（不要把 152.6 与 152.60 判为不同）。
- 只要任何一条不满足：pass=false，并在 rationale 里指出**具体哪个字段**不符、期望与实际各是多少。
- 全部满足：pass=true，score=1；其余情形 score 按满足的字段比例给 0~1 的小数。
