# 深度学习实验二：手写数字分拣（小图分类 · 卷积结构）

## 业务背景

你是某单位数字化小组的算法同学。纸质表单上的**手写数字**（每格扫描成 8×8 灰度缩略图）
要自动分拣成 0~9，直接进录入系统建索引 —— **分错一档就会串档**，所以每一档都要认得出来，
不能只顾样本多的那几档。

**现有做法**：上一版系统把 64 个像素**直接**丢给一个线性分类器（逻辑回归）。
它在扫描质量好的批次上还过得去，但**扫描进纸有偏移**时就会明显掉档 —— 像素位置一变，
固定权重就对不上了。

## 你的任务

用工作目录里的 `data.csv` 训练一个**多轮训练的模型（神经网络）**，产出 `output.json` 与你的图，
达到三条要求：

1. **每一档都认得出**：在测试集上，`macro F1` 要达到达标线，并且**每一档的召回率**都不低于达标线：

   | case | 数据 | 达标线 |
   |---|---|---|
   | `cases/case01` | 1797 张，扫描质量好 | macro F1 ≥ **0.90**，每档召回率 ≥ **0.85** |
   | `cases/case02` | 1639 张，**扫描质量差**（每张平移过 1 像素 + 噪点，数字 0/8 样本更少） | macro F1 ≥ **0.80**，每档召回率 ≥ **0.65** |

2. **训练过程可诊断**：把**逐轮训练历史**（每轮的训练损失与验证损失）写进报告，
   并用**训练曲线**说明什么时候开始过拟合、你是怎么处理的（早停 / dropout / 数据增强…）。
3. **用图把分析讲清楚**：看数据时画图、训练过程画图、评估结果画图，**每张图写一句结论**
   （写进 `figures` 字段）。

> 网络结构（几层卷积、通道数、要不要池化）、优化器、学习率、epoch 数、早停策略、
> 要不要做数据增强都由**你自己决定**（选一个你能讲清楚的即可，不必做多个方案的对比）。
> 达标与否看上面三条是否真的做到（判据见 `judge.md`）。**必须真的训练**：报告里没有逐轮训练历史 = 直接不通过。

## 实验流程（六步，每一步都要走完）

这是一个**完整的小项目**。按下面六步走，②④⑤都要产图（共至少 3 张）：

| 步 | 做什么 | 产出/落点 |
|---|---|---|
| ① **看清需求** | 每一档都要认出来（串档比"多看几张"更贵） | 心里有数 |
| ② **看一眼数据 + 画图** | 有多少张、逐档多少张、图像长什么样（8×8 只有 64 个像素）、有没有扫描偏移的迹象 | `figures/` 里第 1 张图 |
| ③ **定基线** | 上一版系统能做到多少（像素直接进线性分类器），在**同一个测试集**上算 `macro_f1` / `accuracy` | 报告的 `baseline` |
| ④ **训练模型 + 画图** | 把像素还原成 8×8 图像 → 训练卷积网络（**考虑要不要做平移增强**），逐轮记录训练/验证损失，画训练曲线 | 报告的 `training`、第 2 张图 |
| ⑤ **评估 + 画图** | 测试集 `macro_f1` / `accuracy` / 逐档召回率，并**画 10×10 混淆矩阵**看哪两档会被搞混 | 报告的 `metrics`、第 3 张图 |
| ⑥ **写结论** | 每张图一句结论 + 整体判断（`notes`：怎么处理平移、和基线比如何、哪一档最弱、还有什么不足） | 报告的 `figures` / `notes` |

> 图用 `matplotlib` 画（镜像已预装），存到工作目录的 `figures/` 下，例如
> `plt.savefig("figures/evaluation.png", dpi=110)`。**图是给你自己看的** ——
> 但请把"从图里看到了什么"写进 `takeaway`，否则没人知道你看了。
>
> ⚠️ 图里的**标题与坐标轴标签建议用英文**（如 `Confusion matrix`）：运行环境里没有中文字体，
> 中文会渲染成方框。中文解释写在 `takeaway` 和 `notes` 里（那些是给人读的）。

## 数据字典（`data.csv`）

每行是**一张手写数字的缩略图**：64 个像素列 + 1 个标签列。

| 列 | 含义 |
|---|---|
| `pixel_00` … `pixel_77` | 8×8 灰度缩略图，**按行列命名**（`pixel_rc` = 第 r 行第 c 列的像素）。取值 0~1：0 = 背景，越接近 1 笔画越深 |
| `label` | **目标**：这张图是哪个数字（0~9 的整数） |

> 数据来自公开数据集 **UCI Optical Recognition of Handwritten Digits**（sklearn 自带 `load_digits`，
> 1797 张真实手写数字），按 case 做了可复现的改造。
> **case02 是"扫描质量差"的批次**：整张图平移过 1 像素、叠了噪点，而且数字 0 与 8 的样本更少。
> 注意：要把 64 个像素**还原成 8×8 的图像**再看 —— 卷积网络吃的是二维结构，不是一列平铺的数。

## 交付格式

**`output.json`**（写在工作目录下）：

```json
{
  "model": "你最终使用的模型名称（例如 SmallCNN(8-16 channels) + shift augmentation）",
  "n_train": 1347,
  "n_test": 450,
  "metrics": { "macro_f1": 0.93, "accuracy": 0.94, "per_class_recall": [0.9, 0.95, 0.92, 0.9, 0.94, 0.89, 0.95, 0.93, 0.88, 0.92] },
  "baseline": { "name": "linear_on_raw_pixels", "macro_f1": 0.53, "accuracy": 0.58 },
  "training": {
    "epochs_planned": 40,
    "epochs_run": 34,
    "best_epoch": 24,
    "early_stopped": true,
    "history": [
      { "epoch": 1, "loss": 1.9, "val_loss": 1.6 },
      { "epoch": 2, "loss": 1.2, "val_loss": 1.0 }
    ]
  },
  "figures": [
    { "path": "figures/data_overview.png", "takeaway": "10 档里 0 与 8 的样本明显更少；8×8 只有 64 个像素，笔画位置本身就是信息。" },
    { "path": "figures/training_curve.png", "takeaway": "验证损失第 24 轮最低后回升，训练损失还在降 —— 从那里开始过拟合，所以取最优轮次。" },
    { "path": "figures/evaluation.png", "takeaway": "混淆矩阵里错得最多的是 3 被判成 5，两档笔画接近，又容易被平移搅乱。" }
  ],
  "notes": "先按 8×8 还原图像，发现 0/8 样本更少、笔画只有 1~2 像素宽，位置信息很关键。上一版系统（像素直接进线性分类器）macro F1 只有 0.53 —— 位置一偏就失灵。改用两层卷积 + 池化，并在训练时对样本随机平移 ±1 像素做增强，macro F1 升到 0.93，逐档召回最低 0.88。不足：3 与 5 仍会混，可以再加旋转/缩放增强。"
}
```

- `metrics` 必须有 `macro_f1`、`accuracy` 与 **`per_class_recall`（长度 10 的数组，顺序按数字 0~9）**。
- `baseline` 必须是你**自己算出来的**上一版系统成绩：把 64 个像素直接喂给线性分类器
  （例如 `LogisticRegression`），在**同一个测试集**上的 `macro_f1` 与 `accuracy`。
- `training` 必须有 `history`（**每轮一条**，含 `loss` 与 `val_loss`）、`epochs_run`、
  `best_epoch`、`early_stopped`。轮数很多（`epochs_run` > 60）时可按等间隔抽样到约 60 条 —— 完整曲线以训练曲线图为准，别把报告撑得过大。
- `n_train` 指"除测试集以外的全部样本"（含你内部划出的验证集），保证 `n_train + n_test` = 全部行数。
- `figures` 至少三张：看数据（②）、训练曲线（④）、评估（⑤，建议 10×10 混淆矩阵），每张都要有 `path` 与一句 `takeaway`。
- 数值不需要和任何"标准答案"一致 —— 达标看的是"是否真的达到 macro F1 与逐档召回线"。

## 怎么算完成

1. 写一个能跑的方案（推荐做成 Skill 里的一段脚本），能对任意一份同结构 `data.csv`
   产出 `output.json` 与三张图。
2. 在 `cases/case01` 与 `cases/case02`（好批次 / 差批次）上都达标 —— 判据对两个 case 各判一次。
3. 把结论与踩过的坑写进 `SKILL.md` 的「实测档案」。

判据全文见 `judge.md`；怎么自测、包内还有什么，见 `README.md`。
