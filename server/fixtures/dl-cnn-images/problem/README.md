# 题目包：手写数字分拣（小图分类 · 卷积结构）

> 这是本实验的**题目包** —— 一个真实需求（把扫描表单里的手写数字分拣对）、达标线、两批数据，
> 外加**一份示范实现**（`reference/`）供你对照学习。

## 这个实验要学什么

1. **结构要对得上数据**：8×8 的图像是**二维结构**，"哪个像素和哪个像素挨着"是信息。
   把 64 个像素平铺成一行喂给线性分类器，位置一变就失灵 —— 卷积（局部连接 + 池化）就是为这个设计的。
2. **数据增强是"把已知的失真教给模型"**：扫描会偏移，那就训练时也随机偏移一点
   （但别把干净样本全换掉，否则两头都差）。
3. **每一档都要认出来**：串档比"多认几张"更贵，所以看 `macro F1` 与**逐档召回率**，
   而不是只看总体 accuracy。
4. **训练过程要看得住**：逐轮记 `loss` / `val_loss`，用训练曲线判断从哪一轮开始过拟合、取哪一轮权重。
5. **可复现**：固定随机种子、写清切分与训练轮次，别人才能复核你的结论。

## 实验流程（六步）

`task.md` 里写了完整流程（① 看清需求 → ② 看一眼数据 → ③ 定基线 → ④ 训练模型 → ⑤ 评估 →
⑥ 写结论），`reference/scripts/train.py` 是一份**把这六步都走完**的示范（含它画的三张图与图注）
—— 照着走一遍，再换成你自己的做法。

## 两批数据

| case | 规模 | 特点 | 参考水平（上一版系统 → 参考实现） |
|---|---|---|---|
| case01 | 1797 张 | 扫描质量好、10 档均衡 | macro F1 0.971 → **0.982** |
| case02 | 1639 张 | **扫描质量差**：每张平移 1 像素 + 噪点，数字 0/8 样本更少 | macro F1 **0.528** → **0.946** |

> `expected.json` 里的数值**不是标准答案**，而是"参考水平"：判据用它核对你的
> `baseline` 是否可信、并识别"可疑地过于好"的结果。你可以做得比参考实现更好，
> 只要说清是怎么做到的。

## 自测方法

CLI 约定：`train.py <case_dir> <output.json>`（`<case_dir>` 里要有 `data.csv`）。

```sh
for c in cases/*/; do python3 <你的skill>/scripts/train.py "$c" /tmp/out_$(basename "$c").json; done
```

脚本末尾会打印本轮成绩、基线与逐档召回率。判据的其余各项（`training.history`、图的条数、
`per_class_recall` 长度、`notes` 长度）请对照 `judge.md` 自己核一遍。

> 卡住了怎么办：先看 `reference/scripts/train.py` 里对应的那一段。
