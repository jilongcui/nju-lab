# 手写数字分拣 Skill（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 判据只要求"**macro F1 与逐档召回达标 + 逐轮训练历史齐全 + 说清怎么处理扫描偏移**"，
> 所以换通道数/层数、换增强方式（旋转/缩放）、换优化器都能通过，你甚至可以做得更好。
>
> 它与你的起点 `skill-template/` 形态一致（同样的 `load_data` / `to_arrays` / `build_baseline` /
> `train_cnn` / `train_and_evaluate` / `main`），方便逐段对照。

## 能力边界

- 能处理：8×8 灰度小图（列名 `pixel_rc`）+ 10 档标签（`label`），取值为 0~1
- 能处理：与"像素直接进线性分类器"（上一版系统）在**同一测试集**上的对比评估
  （macro F1 / accuracy / 逐档召回）
- 能处理：训练期平移增强、逐轮训练历史的记录与训练曲线绘制
- 不处理：彩色图 / 更大分辨率（`SIDE=8` 写死）、超过 10 档的分类
- 不处理：需要更复杂几何不变性（旋转、缩放、透视）的场景 —— 本实现只做了平移增强
- 不处理：目标列名不同的数据（`label` 写死在 `TARGET`）

## 方法（六步 —— 与 `task.md` 的流程一致）

1. **看清需求** —— 每一档都要认出来（串档最贵），所以看 macro F1 与逐档召回
2. **看一眼数据** —— 逐档样本数、缩略图长什么样、笔画只有 1~2 像素宽（位置就是信息）
3. **定基线** —— 上一版系统：64 个像素直接进 `LogisticRegression`，在同一测试集上算成绩
4. **训练模型** —— 把像素 reshape 成 8×8 → 两层卷积(16/32 通道) + 池化 + 全连接 →
   训练期**半概率平移增强**（±1 像素，零填充）→ Adam + 早停，逐轮记录 `loss` / `val_loss`
5. **评估** —— 测试集 macro F1 / accuracy / 逐档召回 + 10×10 混淆矩阵（哪两档最容易被搞混）
6. **写结论** —— `compose_notes` 把"看过什么 → 怎么处理偏移 → 与基线比如何 → 哪一档最弱"写成一段话

产出结构（`output.json`）见 `task.md`；判据见 `judge.md`。

## 实测档案

- 自测时间：2026 年（实验包验收）
- 达标情况：case01 ✅ / case02 ✅
  （case01 macro F1 0.982（上一版系统 0.971，基础批次里它也过关）；case02 macro F1 0.946 / 上一版系统只有 0.528）
- 踩坑记录（每条写成一行）：
  - **把 64 个像素平铺成一行**在 case02 上直接掉到 macro F1 0.53 —— 位置一变，固定权重就失效
  - 数据增强不能"全批次都平移"：干净批次上反而变差，改成一半批次原样喂进去后两边都稳
  - 8×8 太小，**网络别开大**：16-32 通道足够，再大就开始过拟合（验证损失很早就回升）
  - `stratify=y` 不能省：0 与 8 两档样本更少，不分层会让测试集的类别比例乱跳
