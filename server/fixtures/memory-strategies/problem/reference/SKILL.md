# 记忆系统 Skill（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 判据只看"口径一致 + 更新/遗忘真的生效 + 说得清取舍"，所以函数怎么切、图怎么画都随你。

## 能力边界

- 能处理：`dialogue.csv` + `queries.csv` + `memory_config.json` 这套固定结构（中文对话）
- 能处理：任意轮数与条目数（检索是线性扫描，教学规模下足够快）
- 能处理：一次或多次更正、任意条数的遗忘（阈值由配置给出）
- 不处理：**中文分词**与语义向量（环境里没有分词器、也没有向量模型）—— 所以检索用字符 2-gram 余弦，
  它只认"字面重叠"，换一种问法就可能漏
- 不处理：真实记忆服务（`mem0` 等在本环境**装不了**：无外网）—— 本实验用"本地条目表 + 自己实现的检索"
- 不处理：记忆条目的**互相冲突检测**（只看"旧说法是否出现在更早条目里"这一条明确规则）
- 不做：自动判断"哪条信息重要"（重要性由 category 写死）

## 方法（六步 —— 与 `task.md` 的流程一致）

1. **看清需求** —— 记得住、找得到、改得掉、忘得了：四件事各有各的难处
2. **看懂口径** —— 条目格式、category 顺序、重要性、更新/遗忘阈值、检索口径**都不许改**
3. **写入** —— `build_entries`：哪些轮产生条目、怎么编号、字段怎么填（含 `entries_checksum`）
4. **更新与遗忘** —— `apply_updates`（旧条目失效并挂到新条目）+ `apply_forgetting`（只处理 active）
5. **三种策略** —— `window_*` / `build_summary` / `retrieve` 各算 `recall@k`，并给出 before/after
6. **写结论** —— 三种策略各解决什么、遗忘的代价与合规意义、错误记忆的风险

产出结构（`output.json`）见 `task.md`；判据见 `judge.md`。

## 为什么"四操作"要一起做（本章的教学点）

- **写入**决定了下游一切：`fact` 是**抄下来的原文**，抄错了后面每一步都在用错的；
- **检索**是真正被用上的那一步：本实验里它的 `recall@k` 最高，但它的**前提**是"提问与条目用词能对上" ——
  把提问换成另一种说法就会漏（这正是第 5 章量过的"搜得到字面、搜不到意思"；越过它要靠向量检索，
  但那需要模型，本环境没有）；
- **更新**必须是"旧条目**失效**"而不是"再写一条新的"：否则旧药会一直被检索命中，
  助手就会一直按旧药回答 —— 这就是"错误记忆 = 错误病史"的机器版；
- **遗忘**是不可逆的：本实验里被遗忘的条目在**窗口、摘要、检索三种策略下都取不到**，
  `before_after` 会直接把这件代价量出来。合规上它对应"数据最小化 / 留存期限"，
  但医学场景要小心：被遗忘的可能正是随访需要的。

## 实测档案

- 自测时间：2026-10-10（参考实现复验 2/2 通过）
- 用例通过率：2/2
- 关键数字：
  - case01（P-001，12 轮 → 7 条）：`recall@k` 窗口 **0.3** / 摘要 **0.7** / 检索 **0.8**；
    更新 1 次（`M03` 二甲双胍 → `M07` 达格列净）、遗忘 2 条（`M02` `M06`）；
    `before_after` 里 Q04「散步和抽烟」从 `[M02, M06]` 变成 `[]`
  - case02（P-207，16 轮 → 10 条）：`recall@k` 窗口 **0.25** / 摘要 **0.583333** / 检索 **0.666667**；
    更新 1 次（`M03` 阿托伐他汀 → `M10` 瑞舒伐他汀）、遗忘 5 条
- 踩坑记录（pitfalls）：
  - **顺序不能反**：先抽取 → 再更新 → 再遗忘 → 最后才做三种策略；顺序一乱，状态与指标全变
  - 遗忘**只处理 `active`**：被更正成 `superseded` 的条目不会（也不该）被顺带遗忘 —— 这是边界口径
  - 窗口策略里"能提供的条目"要按**最终状态**算：第 9 轮那条虽然还在窗口里，但它已被遗忘，就不算
  - 摘要要按 `(time, entry_id)` 取同类最新，同类里旧的那条会被压掉 —— 这就是"摘要丢细节"
  - 检索**只保留相似度 > 0** 的条目：一个都不命中时要返回空数组，而不是硬凑够 top-k
  - 字符 2-gram 的文本处理要**只留字母数字**（`str.isalnum()`），标点与空格去掉；中文不需要分词
  - `entries_checksum` 最容易错在**行序与末尾换行**：按 `entry_id` 升序、行间 `\n`、末尾不加
  - 图里的标签一律英文（运行环境没有中文字体），中文只写在 `takeaway` / `notes`
