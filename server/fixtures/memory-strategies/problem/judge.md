评分细则（**应用任务：记忆系统 —— 四操作 + 三种上下文策略**）

⚠️ 条目抽取规则、category 顺序与关键词、重要性取值、更新/遗忘阈值、三种策略与检索口径都已在
`task.md` 里钉死，所以**条目编号与状态、`entries_checksum`、窗口、摘要文本、每题检索命中的条目、
三个 `recall@k`、`before_after` 都是确定的**。这些已由平台用**确定性断言**判定
（见 `manifest.json` 的 `assertions`）：字段完整、条目抽取、校验和、窗口、摘要、检索、
三个指标、**更新真生效**（旧条目不再命中）、**遗忘真生效**（三种策略都拿不回）、
`before_after` 有实际差异、答案引用的条目、图与 `notes` 长度。断言未通过的结果**不会交给你判**，
你不必重算这些数字。

你只需要判断以下**语义**问题（任一项不成立 → 不通过）：

1. **`notes` 是否讲清三种策略各自解决什么问题**：窗口要落到"省 token / 只留最近几轮 ⇒ 久远事实必丢"；
   摘要要落到"压缩率最高 / 同类只留一条 ⇒ 细节被抹平"；检索要落到"按提问取相关 ⇒ 命中率最高，
   但**依赖提问与条目的用词能对上**，换一种问法就可能漏"。只写"三种都试了""窗口最简单"这类空话，
   或把三种策略的作用讲反 → 不通过。
2. **是否理解"更新"与"遗忘"**：更新要说清**旧条目必须失效**（`superseded`），否则以后每次检索都会
   把旧药当成当前用药；遗忘要说清它是**真的不再参与任何一次检索**（不是"藏起来"），
   并至少给出一条**代价或合规意义**（数据最小化 / 留存期限 / 医学场景里被遗忘的可能是随访真正需要的信息）。
   把"遗忘"说成"删掉就好、没有任何影响"、或对更新的后果不加区分 → 不通过。
3. **`figures[].takeaway` 是否"看图说话"且与 `metrics` 自洽**：结论里的三个 `recall@k` 数值必须与报告的
   `metrics` 一致（**允许四舍五入**）；只写"我画了一张柱状图"、或结论与数字矛盾 → 不通过。
4. **有没有正视"错误记忆 = 错误病史"这条风险**：要指出记忆条目是**从对话抄下来的原文**，
   一旦抄错、或更正没生效，后续每一次检索都会把错的当成事实用；并说明下一步该怎么补
   （例如：写入前让患者确认 / 重要事实走人复核 / 记录来源轮次以便回溯）。
   只复述题干、只堆字段名、把 `notes` 写成运行日志 → 不通过。

判定口径：
- 键序、缩进、空白、小数位差异不扣分。口径与数值**由断言负责**，你不必复核；
  你只管「取舍是否讲清」与「结论是否与数字自洽」。
- `score` = 上述语义项的达成程度（0~1）；任一项不成立时 score 不超过 0.5。
- rationale 用中文、**一句话（≤60 字）**说清结论；不通过时指出具体是哪一项。
