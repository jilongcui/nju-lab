# 大语言模型实验：手写注意力 + 消融 + 采样（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 判据只看"口径一致 + 消融方向对 + 说得清机制"，所以函数怎么切、图怎么画都随你。

## 能力边界

- 能处理：`sentences.csv` + `embeddings.csv` + `params.json` 这套固定结构（英文 token、写死的权重）
- 能处理：任意 token 数（注意力是 O(n²)，教学规模下足够快）与任意 `d_model` / `d_head`
- 能做：缩放点积注意力、因果掩码、三档消融的三个统计量、锐化系数下的采样统计
- 不处理：**训练**（权重是给定的，没有损失、没有反向传播、没有梯度）
- 不处理：多头拼接与多层堆叠（本例只有单个头、单层）
- 不处理：真实文本生成（采样段只是"给定 logits 看分布怎么变"，没有解码循环）
- 不做：把注意力权重当作**因果解释**（它只说明"看了哪里"）

## 方法（六步 —— 与 `task.md` 的流程一致）

1. **看清需求** —— 注意力的本质是"软对齐"：把"该看谁"变成一组和为 1 的权重
2. **看懂口径** —— 切 token、缩放因子、掩码方向、校验和格式、采样顺序**都不许改**
3. **算注意力** —— `attention_weights`：Q/K/V → `QKᵀ` → `/√d_head` → 因果掩码 → 逐行 softmax
4. **消融对照** —— `run_ablation`：三档各报 `max_row_weight` / `entropy` / `mean_future_weight`
5. **采样与画图** —— `run_sampling`（逆变换采样，每个系数同一串随机数）+ 两张图
6. **写结论** —— `compose_notes`：两个机制各自防什么、Q/K/V 的分工、局限

产出结构（`output.json`）见 `task.md`；判据见 `judge.md`。

## 为什么这三个数（而不是"跑通"）才是重点（本章的教学点）

- **`max_row_weight` 与行熵是一对反向量**：一个量"多尖"、一个量"多散"。
  去掉 `√d` 缩放后分数被放大，softmax 饱和 → 最大权重涨、熵掉；
- **`mean_future_weight` 是"有没有偷看未来"的直接证据**：掩码生效时它恒为 0；
  去掉掩码后 > 0 —— 训练时等于提前看到答案，而且解码不能逐步进行；
- **`√d` 的分母不是"拍脑袋"**：点积是 d 项之和，方差随 d 线性增长（这里 `d_head=4`，标准差约翻倍），
  除以 `√d` 把方差拉回 1 附近，softmax 才落在"有区分度但不饱和"的区间；
- **`top1_ratio` 靠样本量说话**：锐化系数越大分布越平，200 次里抽到 top-1 的比例就越低 ——
  这与"模型输出概率 ≠ 每次都选概率最大的那个词"是同一件事。

## 实测档案

- 自测时间：2026-10-10（参考实现复验 2/2 通过）
- 用例通过率：2/2
- 关键数字：
  - case01：31 个 token / 26 个不同 token / 校验和 `8d16d6b80dda`；
    消融 `max_row_weight` **0.2761 → 0.4329**（去缩放）、熵 **2.2074 → 1.7238**；
    去掩码 `mean_future_weight` **0.4725**、熵 **3.1066**；
    采样 `top1_ratio`：**0.745（s=0.5）→ 0.540（s=1.0）→ 0.360（s=2.0）**
  - case02：44 个 token / 校验和见 `cases/case02/expected.json`；
    去缩放 `max_row_weight` **0.3149 → 0.5296**、熵 **2.2831 → 1.5123**
- 踩坑记录（pitfalls）：
  - **掩码位必须是 `-inf`（或极小值）而不是 0**：置成 0 会变成"权重 0 也参与归一化"，行和就不再是均匀的语义
  - 软掩码前先算"逐行最大值"是数值稳定的关键；掩码位 `-inf - 有限值 = -inf`，`exp` 后正好是 0
  - `top_attend` 要取**并列时最小列号**（`np.argmax` 正好是"第一个最大值"，自己写循环要小心）
  - 校验和最容易错在**行序与末尾换行**：行内 `,`、行间 `\n`、末尾不加
  - 采样要对**每个锐化系数重新初始化** `random.Random(4100)`（否则三个系数用的是不同的随机序列，
    `samples` 就对不上）—— 这叫"共用随机数"，也让不同系数的差异只来自分布
  - 图里的标签一律英文（运行环境没有中文字体），中文只写在 `takeaway` / `notes`
