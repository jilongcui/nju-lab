# 参考实现（示范）

> 出题时的示范：一份走完六步的 `scripts/solve.py`。平台不检查这份内容，只要求它在题包里。

## 怎么做

1. `nx.DiGraph()` + `add_edge(head, tail, relation=...)` 把 18 条三元组建成有向图；
2. 禁忌证查询：遍历 `P -医嘱使用-> D`，看 `D -禁忌证-> C` 且 `P -患有-> C`；
3. 相互作用查询：遍历 `P -正在服用-> A`，看 `A -相互作用-> B` 且 `P -新开医嘱-> B`，
   `risk` 取 `B` 的 `不良反应`（字典序第一条）；
4. 每条预警都写 `path`（2~3 段字符串），排序口径写死；
5. 画"每个患者的预警条数"柱状图（轴标签英文）。
