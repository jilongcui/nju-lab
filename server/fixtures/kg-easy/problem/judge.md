# 评分细则（语义判据）

> 硬性条件由 `manifest.json` 的 `assertions` 判定（两条查询逐条比对、路径非空、图规模、图与 notes）。
> 这里只判**语义**，任一项不成立 → 不通过。

1. **`notes` 是否是"自己写的"**：要说出两条查询各自沿哪条边走、为什么是"两跳"、路径为什么重要
   （可解释性）。空话或照抄模板 → 不通过。
2. **`evaluation` 与 `graph` 是否自洽**：预警里出现的患者/药物/疾病都在三元组里，节点数与边数对得上。
3. **图是否"看图说话"**：`takeaway` 要说清哪个患者有几条预警，与 `evaluation` 矛盾 → 不通过。
4. **是否手写结果**：如果 `path` 的措辞与三元组对不上（方向反了、跳数不对）→ 不通过。
