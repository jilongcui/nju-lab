# mcp-easy —— 入门实验：手写一次 MCP 往返（工具协议 · 容易）

> 对应课程章节：**工具扩展：MCP 服务**（动手实践：不装 SDK、不联网，亲手跑一遍三步往返）。
> 难度 **easy**：一行一条 JSON-RPC，只用 Python 标准库 + `matplotlib`。

## 场景与数据

- 应用：药品 / 检验查询服务器 —— 医生问"P001 最近几次 HbA1c"，智能体通过工具拿到真数据。
- 数据：`problem/cases/case01`（2 个工具 / 9 条请求）、`case02`（3 个工具 / 6 条请求），
  每个 case 三个输入：`tools.json`、`data.json`、`requests.jsonl`（含一条通知、若干错误请求）。
- 造题：`tools/gen_cases.py`（固定数据、可重跑；**不下发**）。

## 判据设计要点

1. **逐条报文比对**：`responses` 与 `expected.json` 完全一致（`result` / `error` / 不响应三种形态），
   `-32602` 与 `-32601` 各出现几次也单独断言 —— 错误码混用直接抓。
2. **两条语义边界**：通知（无 `id`）**不产生响应**；查不到药/组合/检验是 `isError:true` 的**正常返回**，
   不是 `error`。这两条是本章最容易被写错的地方。
3. **运行时发现**：case02 的 `discovered.tools` 必须自动变成 3 个（多出 `query_labs`）——
   证明工具清单是问出来的、不是硬编码的。
4. **防退化**：所有请求都回同一条响应 → `responses` 逐条比对立刻失败。
5. **口径钉死**：工具返回文本逐字对（含全角标点）；相互作用按药名字典序查表，两种顺序都对。

## 项目字段文案（建项目时用）

- **title**：入门实验：手写一次 MCP 往返（工具协议 · 容易）
- **difficulty**：`easy`
- **content**（学生详情页首屏；不写"你的任务"）：
  医生问"P001 最近几次 HbA1c"，模型答不上来 —— 它拿不到检验库。MCP 就是"怎么问工具、怎么答"的标准格式。
  这个实验不装 SDK、不联网：你手写服务器那一侧，把 initialize、tools/list、tools/call 三步跑通。
- **objectives**：
  1. 能读懂一次 MCP 调用的三段报文（握手 / 清单 / 调用）各自在做什么；
  2. 能区分 `result` 里的 `isError` 和协议层的 `error`，并说清混用后果；
  3. 能解释"运行时发现"为什么让加工具不用改客户端。
- **background**（每条 = 概念 + 一句人话解释）：
  - **JSON-RPC 2.0**：一行一条 JSON，`id` 对应请求与响应；没有 `id` 的通知不需要应答。
  - **inputSchema**：写给模型看的说明书（参数名、类型、必填），模型照它填参数。
  - **isError**：工具"正常回答了一个坏消息"（查不到）—— 让模型换说法，而不是以为请求写错了。
  - **协议错误码**：`-32602` 参数不合法（工具名错、缺参数）、`-32601` 方法不认识。
  - **运行时发现**：`tools/list` 问一次就拿到当前能力清单，加工具只改服务器。
- **description**：
  1. 读实验内容与 `task.md` 的三类响应、两种错误码、三种工具文本；
  2. 先做 `initialize` 与 `tools/list`，确认清单能原样返回；
  3. 再写 `tools/call`：查工具名 → 查必填参数 → 执行；
  4. 跑两个 case，重点看通知不回、`isError` 与 `error` 的差别、case02 多出的 `query_labs`；
  5. 画响应类型柱状图（轴标签英文），填 `report.md`（六节，含踩坑 ≥1 条）。

## 实测记录（出题时）

- 参考实现两个 case 全对：`responses` / `discovered` / `stats` 与 `expected.json` 一致；
- case01：9 条请求 → 8 条有响应、1 条通知不回；协议错误 2 条 `-32602` + 1 条 `-32601`；`isError` 1 条（布洛芬未收录）；
- case02：6 条请求 → 5 条有响应、1 条通知；`discovered.tools` 自动变成 3 个（含 `query_labs`）。
