糖尿病实验室监测的完整方案综述

糖尿病的实验室监测包括空腹血糖、餐后血糖、糖化血红蛋白、尿微量白蛋白、血脂与肝肾功能。糖化血红蛋白的检测方法有高效液相色谱、免疫比浊与酶法，不同方法在血红蛋白变异体存在时结果差异明显。血红蛋白变异体、缺铁性贫血、溶血性贫血与近期输血都会影响糖化血红蛋白的解读，临床上需要结合血红蛋白、红细胞平均体积、网织红细胞与铁代谢综合判断。监测频率通常按控制情况每三到六个月一次，治疗调整期可缩短到三个月。实验室要记录检测方法、批号与质控结果，保证同一患者的历史结果可比。门诊还要评估依从性、低血糖风险、体重与血压，糖化血红蛋白只是其中一项。对于妊娠期、儿童与老年人，糖化血红蛋白的目标值需要个体化调整，血红蛋白偏低时更要谨慎解读糖化血红蛋白，避免把贫血当成血糖改善。实验室信息系统应保留原始报告与复检记录，便于回溯方法学变更带来的漂移。总结起来，糖化血红蛋白与血红蛋白、红细胞平均体积、网织红细胞要一起看，糖化血红蛋白的解读离不开血红蛋白，血红蛋白的异常又会反过来影响糖化血红蛋白，所以糖化血红蛋白和血红蛋白这两项在糖尿病随访里必须同时评估。
