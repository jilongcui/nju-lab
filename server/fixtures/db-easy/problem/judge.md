# 评分细则（语义判据）

> 硬性条件由 `manifest.json` 的 `assertions` 判定（四条查询逐字段比对、字段完整、图与 notes）。
> 这里只判**语义**，任一项不成立 → 不通过。

1. **`notes` 是否是"自己写的"**：要说出四条查询各用什么 SQL（过滤 / `GROUP BY` / `HAVING` / `AVG`）、
   排序口径怎么处理、两个 case 的差别（行数、科室分布）。照抄模板或空话 → 不通过。
2. **`schema` 与查询是否自洽**：声明的列类型与真实 CSV 一致，主键是 `visit_id`。
3. **图是否"看图说话"**：`takeaway` 要说出哪个科室最多、大概占比；与 `q2_by_department` 矛盾 → 不通过。
4. **是否手写了结果**：如果 `loaded.rows` 与查询结果对不上（例如直接抄 `expected.json` 却写错行数）→ 不通过。
