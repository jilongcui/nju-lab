# 会员价值分级 Skill（参考实现 · 学习示范）

> 📖 这份实现**随题目包一起下发**（`problem/reference/`），是给你的**示范** —— 不是标准答案。
> 达标只要求"**macro F1 ≥ 0.60 且每一档召回 ≥ 0.50** + 说清选择"，换模型、换特征都能通过。
>
> 它与你的起点 `skill-template/` 形态一致（同样的 `load_data` / `build_baseline` /
> `train_and_evaluate` / `main`），方便逐段对照。

## 能力边界

- 能处理：数值特征 + 三分类标签（`tier` 取 0/1/2）的表格数据，列名与 `data.csv` 一致
- 能处理：**特征量纲差异大**的情况（先标准化再训练）
- 能处理：类别不均衡下的评估（macro F1 + 逐档召回）
- 不处理：缺失值填充、类别型特征编码、类别数不等于 3 的数据（`per_class_recall` 会随之变化）

## 方法（四步）

1. **读数据** —— 看清有哪些列（数据字典见 `task.md`）
2. **先算现有做法的成绩** —— 一律判为多数类（低档）：accuracy 有 0.40，但 macro F1 只有 0.19
3. **预处理 + 训练** —— 各列量纲差很多（消费额 vs 次数），**标准化**后再训练
4. **用 macro 视角评估** —— 逐档召回 + macro F1，而不是只看 accuracy

## 关键点：为什么看 macro F1

三档人数不平均（约 40% / 35% / 25%）。accuracy 会被"人最多的低档"主导：

| 方案 | accuracy | macro F1 | 逐档召回 |
|---|---|---|---|
| 一律判低档（现有做法） | 0.40 | **0.19** | [1.00, 0.00, 0.00] |
| 只看 accuracy 调出来的"偷懒"模型 | 0.55 | 0.45 | 偏高、偏低、很低 |
| 本实现：标准化 + 多分类逻辑回归 | 0.77 | **0.77** | [0.84, 0.71, 0.75] |

> 判据同时卡 macro F1 **和每一档的召回**：前者防"只保大类"，后者防"直接放弃人少的档位"。
