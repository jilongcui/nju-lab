# 题目包：分拣手写数字（入门 · 神经网络三分类）

> 这是本实验的**题目包** —— 一个很直观的需求（把 8×8 小图上的 3/8/9 分开）、判据、两批数据，
> 外加**一份示范实现**（`reference/`）供你对照学习。

## 这个实验要学什么

1. **神经网络在做什么**：输入 64 个像素 → 一层隐藏层做加权组合 → 输出三个类别的分数；
   训练就是"反复算损失、按梯度调参数"。
2. **"真的训练了"长什么样**：看得到逐轮损失下降（`training.history`），而不是只报一个结果。
3. **基线意识**："一律猜最多"只有 1/3 正确率 —— 有了这个参照，"accuracy 0.95"才说明问题。
4. **混淆矩阵**：3、8、9 笔画相近，错在哪一对要靠混淆矩阵看，而不是只知道"错了几个"。
5. **过拟合的苗头**：训练损失接近 0 时，要留意"训练集拟合得很好、测试集不一定"。

## 实验流程（六步）

`task.md` 里写了完整流程（① 看清需求 → ② 看一眼数据并画图 → ③ 定基线 → ④ 训练网络 →
⑤ 评估并画图 → ⑥ 写结论），`reference/scripts/train.py` 是一份**把这六步都走完**的示范 ——
照着走一遍，再换成你自己的做法。

## 两批数据

| case | 规模 | 特点 | 参考水平（基线 → 参考实现） |
|---|---|---|---|
| case01 | 537 行（3/8/9 各约 180） | 原始扫描质量 | accuracy 0.34 → **0.98**（macro F1 0.98） |
| case02 | 360 行（各 120）+ 扫描噪声 | 样本更少、像素有抖动 | accuracy 0.33 → **0.97**（macro F1 0.97） |

> `expected.json` 里的数值**不是标准答案**，而是"参考水平"：判据用它核对你的
> `baseline.accuracy` 是否可信、并识别"可疑地过于好"的结果。
> 本任务确实容易（只有三个数字），做到 0.97 左右是正常的；测试集一个都不错时请说明是怎么做到的。

## 自测方法

CLI 约定：`train.py <case_dir> <output.json>`（`<case_dir>` 里要有 `data.csv`）。

```sh
# 两个 case 都跑一遍，看是否达标（accuracy ≥ 0.92、macro F1 ≥ 0.90）
for c in cases/*/; do python3 <你的skill>/scripts/train.py "$c" /tmp/out.json; done
```

脚本末尾会打印 `[达标] / [未达标]` 与各项数值。判据的其余各项（训练历史、切分占比、`notes`）
请对照 `judge.md` 自己核一遍。

> 卡住了怎么办：先看 `reference/scripts/train.py` 里对应的那一段（尤其是 `train_model` 的训练循环）。
