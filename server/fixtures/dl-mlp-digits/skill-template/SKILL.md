# 手写数字分拣 Skill（你的方案）

> **这是入门实验，重点是"看懂神经网络怎么训练起来"**：输入 → 网络 → 损失 → 反向传播调参数。
> 网络结构、优化器、轮数都由你决定，达标看的是
> "**accuracy ≥ 0.92 且 macro F1 ≥ 0.90** + **真的训练了（损失在降）** + 能不能用图说清"。

## 实验材料（都在题目包 `problem/` 里，领取后工作区就有）

| 材料 | 作用 |
|---|---|
| `task.md` | 业务背景 + 三条要求 + 数据字典 + 交付格式 |
| `judge.md` | 判据：达标线、训练历史的核对方式 |
| `reference/` | 一份**示范实现** —— 先读它，再写你自己的（它不是标准答案） |
| `cases/case01`、`cases/case02` | 两批数据，自测用 |

**实验流程（六步，与 `task.md` 一致 —— 每一步都要走完）**：

| 步 | 做什么 | 落在哪 |
|---|---|---|
| ① 看清需求 | 3/8/9 三个数字都要认；并且真的训练了 | 心里有数 |
| ② **看一眼数据 + 画图** | 每行是一张 8×8 小图；三类各多少、笔画差在哪 | `figures/` 里第 1 张图 |
| ③ 定基线 | 一律猜训练集里最多的数字 | 报告的 `baseline` |
| ④ **训练模型** | 小网络 + 逐轮记录训练损失 | 报告的 `training.history` |
| ⑤ **评估 + 画图** | 算 accuracy / macro F1，画训练曲线与混淆矩阵 | `figures/` 里第 2、3 张图 |
| ⑥ **写结论** | 每张图一句结论 + 整体判断（损失怎么变、错在哪类） | 报告的 `figures` / `notes` |

材料配合：`task.md`（需求 + 流程）→ 读 `reference/`（一份**走完这六步**的示范，含三张图与各自结论）→ 回 `scripts/train.py` 走自己的六步 → 两个 case 都跑 → 补全能力边界，并把自测记录写进同级的 `dossier.md` → 提交。

## 能力边界

> 这一节是技能说明书的一部分（什么时候该用、不该用我）。下面是按本实验口径给的默认表述，**平台不检查这一节**；如果你的实现有额外限制，按实际情况补两句即可。

- 能处理：与 `data.csv` 同结构的 8×8 像素 + 3/8/9 三类
- 能处理：与"一律猜最多"基线的对比评估，并给出逐轮训练损失
- 不处理：其它数字（0/1/2/4/5/6/7）；不是 8×8 的图片；样本极少时的过拟合；像素取值范围与 0~16 不同的数据
- 写死的假设：输入固定为 64 维、类别固定为 3/8/9，标签到 `CrossEntropyLoss` 下标的映射是固定的

## 要做的决策（本实验的重点）

1. **网络结构**：隐藏层要几个单元？为什么？（太大容易过拟合，太小可能学不动）
2. **训练超参**：学习率、轮数怎么定？看损失曲线判断"还该不该继续训"。
3. **基线**：现有做法怎么算？为什么"一律猜最多"在这个数据上只有 1/3？
4. **评估**：混淆矩阵告诉你什么？训练损失很低、但测试集仍会错，说明什么？
