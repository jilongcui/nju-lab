# 评分细则（教师 rubric）

> **本实验没有标准答案。** 同一件事有很多种做对的写法，所以不比对参考答案。
>
> 平台自动分只是**冒烟建议分**（产物齐不齐、是不是真的调了模型、工具是不是真的跑了、
> 引用有没有依据）。**最终成绩由教师按下面四维打分**，可以覆盖自动分。
>
> 判的是"这个人会不会搭 agent"，不是"输出长得像不像某份答案"。

总分 100 分，四维：

| 维度 | 分值 | 看什么 |
|---|---|---|
| A 任务完成度 | 40 | 6 组对话里，该查到的查到没有、该算的算对没有、该拒的拒了没有 |
| B 循环设计 | 25 | 真的是"模型决定下一步"的循环，还是把步骤写成了流水线 |
| C 工具与记忆的真实性 | 20 | 工具真读文件、记忆真跨轮生效、更正真的替换旧事实 |
| D 报告与边界 | 15 | `notes` 是否讲清了取舍与局限、边界是否守得住、引用是否有据 |

## A 任务完成度（40）

按 6 组对话逐组计分（每组 6-7 分），看最终 `answer` 是否解决了用户的问题：

| 组 | 应达到 | 常见扣分 |
|---|---|---|
| `T1_lookup` | 报出 A-01 的 `last_service_on`，并判断是否该保养（90 天周期） | 只复述台账、不算是否逾期 |
| `T2_overdue` | 给出逾期设备清单（按天数降序），指出最长者与天数，并说明周期出处 | 清单漏设备、天数算错、说不出周期依据 |
| `T3_memory` | 第 2 轮之后默认只谈 A 区（不需要用户重复说） | 每轮都反问"哪个区" = 记忆没生效 |
| `T4_correct` | 更正后按 B 区回答 | 仍按 A 区回答 = 更正没生效（重点扣） |
| `T5_manual` | 说出压差 0.05 兆帕 / 不超过 90 天，并给出 `KB-03` | 数值对但给不出编号 |
| `T6_refuse` | 第 1 轮拒答且不给结论；第 2 轮转为给保养记录与手册要求 | **直接回答"还能用几个月"= 越界，本组 0 分** |

> 数据是对的还答错、或答对了但引错段落的，按"半组"给分。

## B 循环设计（25）

| 分档 | 特征 |
|---|---|
| 21-25 | 模型每步返回动作，代码执行后把**观察**回填再问模型；步数上限真的生效；能处理"模型给了不存在的工具"这类异常 |
| 14-20 | 是循环，但观察回填不完整（模型看不到工具结果就继续猜）；或步数上限写成死循环靠 break 兜底 |
| 6-13 | 每轮只调一次模型就直接出答案，工具由代码按固定顺序调（本质是流水线，不是循环） |
| 0-5 | 没有循环、没有模型调用，或输出是手写/拼接的常量 |

看 `dialogues[].turns[].steps`：一个"每轮步数 ≥ 2"且每步 `observation` 非空的轮次是健康信号；
**全部轮次都只有 1 步**要警惕（可能压根没让模型决定下一步）。

## C 工具与记忆的真实性（20）

工具（10）：`query_assets` / `overdue_assets` / `search_manual` 都真的读了 `assets.csv` / `kb/`。
抽查办法：挑一条 `observation`，自己按 `assets.csv` / 手册复算一遍，对得上才算真。

记忆（10）：

- 写入：`T3` 第 1 轮的"我负责 A 区"进了 `memory.entries`；
- 应用：`T3` 第 2 轮起 `memory.applied` 里有记录，且回答真的用了；
- 更正：`T4` 第 2 轮之后旧值 `state` 变成 `superseded` 或等价状态，`active` 里只剩 B 区。

把记忆写成"每轮把全部历史塞进 prompt"也能用，但要在 `notes` 里说明得失（否则本项最多 6 分）。

## D 报告与边界（15）

| 项 | 分 |
|---|---|
| `notes` 讲清了循环怎么收敛、记忆为什么这么设计、**至少一条局限** | 6 |
| 边界：`T6` 拒答且把话题引回可查的东西 | 5 |
| 引用有据：`citations` 的编号真的出现在本轮 `search_manual` 结果里 | 4 |

## 教师抽查清单（3 分钟）

1. `llm.total_calls` 与 `metrics.llm_calls` 一致，且明显大于"轮数"（说明每轮不止一次调用）；
2. 任挑一轮，看 `steps` 里 `observation` 是不是工具的真实输出（不是"已查询"这种占位）；
3. 打开 `T4`，确认 B 区生效、A 区不再出现；
4. 打开 `T6` 第 1 轮，`refused=true`、`citations=[]`；
5. 看图与 `notes` 是否对应（图上说的和文字说的是不是一回事）。

> 若产物与实现明显不符（例如 `output.json` 里有 26 次模型调用，但 `agent/loop.py` 里一次都没发请求），
> 按学术不端处理，不是扣分问题。
