# 包内说明（搭建型实验 · 给你的材料）

| 文件/目录 | 作用 |
|---|---|
| `task.md` | **题干**：场景、六件硬要求、怎么跑、交付格式 |
| `judge.md` | **评分细则**：教师按它四维打分（也公开给你看 —— 照着自己对齐就行） |
| `assets.csv` | 设备台账 11 台 |
| `tools.json` | 三个工具的名册与参数（工具要你实现） |
| `limits.json` | 每轮步数上限 / 检索取前几条 / 记忆窗口 / 判定基准日 / 各类设备保养周期 |
| `kb/KB-0N.md` | 维护手册 5 篇（文件名去掉 `.md` 就是段落编号） |
| `tasks/T*.jsonl` | 6 组真实对话，一组一个文件 |

> **没有 `expected.json`**：这个实验没有标准答案。机器只做冒烟检查，质量由教师按
> `judge.md` 的 rubric 打 —— 所以不要猜"标准输出长什么样"，去把 agent 做对。

## 本地自测

```sh
cd <你的 skill 根>
python3 scripts/run.py --tasks <题目包>/tasks --out output.json --only T1_lookup   # 先跑一组
python3 scripts/run.py --tasks <题目包>/tasks --out output.json                    # 全跑
```

跑之前确认环境里有 `DEEPSEEK_API_KEY`（平台工作台默认已配）。

## 常见问题

| 现象 | 原因 | 怎么做 |
|---|---|---|
| `未找到 DEEPSEEK_API_KEY` | 环境没配 | 平台工作台自带；本地自测时自己 export |
| 模型返回的不是 JSON | 系统提示没说清 | 在 `loop.py` 的系统提示里明确"只输出一个 JSON 动作" |
| 每轮都只有 1 步 | 你把工具调用写成了"调完模型就直连工具" | 循环是：模型 → 动作 → 执行 → 观察 → **再问模型** |
| `T4` 还按 A 区回答 | 更正没替换旧事实 | 更正时把旧条目置 `superseded`，`active` 里只留新值 |
| `T6` 直接答了寿命 | 漏了 `KB-05` 的边界 | 系统提示里把"剩余寿命不得远程下结论"写成硬规则 |
| 引用编号被判无据 | 编号不是检索出来的 | 只能引用 `search_manual` 当轮返回里的编号 |
| 跑完 token 花了太多 | 每轮把全部历史塞 prompt | 记忆要摘要，别每轮回放全文 |

## 时间不够时的最小路径

1. **先让 `T1_lookup` 跑通**：`loop.py` 里做到"模型 → 一个工具 → 观察 → 模型 → finish"；
2. **再补工具**：三个工具都真读 `assets.csv` / `kb/`；
3. **再补记忆**：先支持写入与应用，最后补更正；
4. **最后补边界与出处**：`KB-05` 拒答 + 引用只取检索结果。

> 每跑完一步就看 `output.json` 对应字段，比一次写完美再 debug 快得多。
