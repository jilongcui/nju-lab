# 包内说明（开放实验 · 给你的材料）

| 文件/目录 | 作用 |
|---|---|
| `task.md` | **题目**：要你做什么、交什么、怎么评 |
| `judge.md` | 评分细则（公开 —— 照着对齐就行） |
| `assets.csv` | 设备台账 11 台 |
| `kb/KB-0N.md` | 维护手册 5 篇（文件名去掉 `.md` 就是段落编号） |
| `tools.json` | 三个工具的名册（用不用随你） |
| `limits.json` | 保养周期、判定基准日、拒答话术 |

> **没有示例代码、没有测试用例、没有"标准答案"**：这个实验要你自己从零做出来。
> 唯一的硬约定是交付形态（`agent/api.py` 的 `handle()` + 数据放包根），
> 因为平台要靠它把东西装起来跑。

## 做完之后

把整个包的目录（含 `agent/api.py` 和四份数据）打成 zip 提交，然后在「我的应用」里
用这次提交创建应用 —— 平台会把它装起来，给你一个能对话的地址。
