# 分子医学学习助手（你的方案 · 收官实验）

> **本实验不给参考实现**（前 18 章的包里都有 `reference/`，这一章没有）。
> 给你的是**需求 + 数据 + 交付契约**，要你把已经学过的东西**自己组装起来**：
> 记忆（第 16 章）、工具调用（第 17 章）、技能流程（第 18 章）、检索与出处（第 5 / 9 章）、安全边界（第 18 章）。
>
> 五件事**必须真的发生**（不是加分项）：① 记忆读写（跨轮应用）② 工具调用（按 schema 校验，非法如实记 rejected）
> ③ 技能流程（按模板成文）④ 检索 + 出处（行级 / 段级）⑤ 安全边界（越界升级 + 拒答）。

## 实验材料（都在题目包 `problem/` 里，领取后工作区就有）

| 材料 | 作用 |
|---|---|
| `task.md` | **题干**：需求、六步流程、五件事的契约、数据字典、交付格式 |
| `judge.md` | 判据：哪些是硬性口径、哪些是语义判断 |
| `cases/case01`、`cases/case02` | 两套输入（六份文件）+ `expected.json`（自测用） |

**实验流程（六步，与 `task.md` 一致 —— 每一步都要走完）**：

| 步 | 做什么 | 落在哪 |
|---|---|---|
| ① 看清需求 | 五件事分别对应哪一章的本事、各自难在哪 | 心里有数（写进 `notes`） |
| ② 摸清材料 | 六份文件怎么对上（提问 / 数据行 / 段落 / 名册 / 调用 / 模板） | 心里有数 |
| ③ **搭最小闭环** | 记忆、工具、报告、引用、安全 —— 五段各写一个函数 | 代码 |
| ④ **逐环跑通** | 每一环单独验证：条目 / 调用结论 / 四节 / 引用格式 / 升级与拒答 | 报告的四个部分 |
| ⑤ 汇总与画图 | 各指标均值 + 越界行数（图上标签用 ASCII） | `key_facts` / `figures` |
| ⑥ 写结论 | 每一环为什么这么做、检索结果 ≠ 结论、至少两条局限 | `notes` |

## 要做的决策（本实验的重点）

1. **记忆为什么只记"薄弱点"**：如果把整段对话都存下来，后面检索会有什么问题？
   你的实现里"什么时候写、什么时候用"是怎么定的？
2. **非法的工具调用该不该出现在报告里**：如果悄悄跳过，会丢掉什么信息？
   你的 `rejected_reason` 是怎么分的（哪几种情况）？
3. **"引用"和"结论"的界限在哪**：`experiment_data.csv:R02` 这个引用说明了什么？
   它**没有**说明什么？报告里哪些话是你**不该写**的？
4. **越界读数为什么要升级而不是照答**：如果读数其实是测错的，照答会有什么后果？
