# 入门实验：按花瓣尺寸识别鸢尾花品种（三分类）

## 业务背景

你是园艺场的实习生。场里有一批鸢尾花，老师傅靠经验看花瓣就能说出品种：

- **setosa（山鸢尾）**：花瓣又短又窄；
- **versicolor（变色鸢尾）**：中等；
- **virginica（维吉尼亚鸢尾）**：花瓣最长最宽。

现在要把这份经验做成一个"看尺寸报品种"的小工具：**量一下花瓣的长和宽 → 说出品种**。
你手上是 150 朵花的手工测量记录，三个品种各 50 朵。

**现有做法（基线）**：不做任何判断，一律报"场里最多的那个品种"。
它在这个三分类问题上大约只有 **1/3** 的正确率 —— 所以你的任务不是"跑个模型"，
而是**比这个现有做法明显更好**。

## 你的任务

用工作目录里的 `data.csv` 做一个品种判断方案，产出 `output.json` 和你的图，达到三条要求：

1. **达标**：在测试集上 **accuracy ≥ 0.90**，且 **macro F1 ≥ 0.85**。
   后者是"三个品种平均都要认得"——只认 setosa 和 versicolor、把 virginica 全丢掉是过不了的。
2. **可复现**：切分与训练用固定随机种子；产出里写清 `n_train` / `n_test`
   （测试集占比 **20%~40%**，怎么切由你决定）。
3. **用图把判断讲清楚**：看数据时画一张图、评估结果时画一张图，并给每张图写一句结论
   （写进 `output.json` 的 `figures` 字段）。

> 这是**入门实验**：只有两个特征、任务也很小。模型由**你自己决定**
> （逻辑回归、决策树、KNN 都可以），选一个你能讲清楚的即可，不必做多个方案的对比。

## 实验流程（六步，每一步都要走完）

| 步 | 做什么 | 产出/落点 |
|---|---|---|
| ① **看清需求** | 三个品种都要认出来；比"一律猜最多"明显更好 | 心里有数 |
| ② **看一眼数据 + 画图** | 两个花瓣特征怎么分布？哪两类分得开、哪两类重叠？**画一张散点图** | `figures/` 里第 1 张图 |
| ③ **定基线** | 不建模能做到多少（一律猜训练集里最多的品种） | 报告的 `baseline` |
| ④ **训练模型** | 选一个模型，固定种子切分后训练 | 报告的 `model` / `metrics` |
| ⑤ **评估 + 画图** | 算 accuracy 与 macro F1，**画一张混淆矩阵**看哪两类会混 | `figures/` 里第 2 张图 |
| ⑥ **写结论** | 每张图一句结论（`figures[].takeaway`）+ 整体判断（`notes`：难在哪、还有什么不足） | 报告的 `figures` / `notes` |

> 图用 `matplotlib` 画（镜像已预装），存到工作目录的 `figures/` 下，
> 例如 `plt.savefig("figures/data_overview.png", dpi=110)`。
>
> ⚠️ 图里的**标题与坐标轴标签用英文**（如 `petal length (cm)`）：运行环境里没有中文字体，
> 中文会渲染成方框。中文解释写在 `takeaway` 和 `notes` 里（那些是给人读的）。

## 数据字典（`data.csv`）

| 列 | 含义 |
|---|---|
| `petal_length_cm` | 花瓣长度（cm） |
| `petal_width_cm` | 花瓣宽度（cm） |
| `species` | **目标**：品种（`setosa` / `versicolor` / `virginica`） |

> 数据是机器学习里最经典的鸢尾花测量数据（这里只取两个花瓣特征，方便画图）。
> 规律很直观：**setosa 的花瓣明显更短更窄**，与另外两类几乎完全分开；
> **versicolor 与 virginica 在花瓣宽度上有重叠** —— 这就是本题主要的失分点。

## 交付格式

**`output.json`**（写在工作目录下）：

```json
{
  "model": "你最终选择的模型名称（例如 LogisticRegression / DecisionTree / KNN）",
  "n_train": 112,
  "n_test": 38,
  "metrics": { "accuracy": 0.95, "macro_f1": 0.95 },
  "baseline": { "name": "most_frequent", "accuracy": 0.33 },
  "figures": [
    { "path": "figures/data_overview.png", "takeaway": "setosa 的散点单独挤在左下角，另两类在花瓣宽度上重叠——难点在后者。" },
    { "path": "figures/evaluation.png", "takeaway": "对角线是判对的样本；versicolor 有 1 朵被判成 virginica，因为它的花瓣尺寸正好在交界处。" }
  ],
  "notes": "先画散点确认 setosa 完全分得开、另两类在花瓣宽度 1.3~1.8cm 重叠；用逻辑回归（两个特征都用上）在测试集上 accuracy 0.95、macro F1 0.95，比「一律猜最多品种」的基线（0.33）高很多。不足：样本量小，重叠区靠线性边界分不干净。"
}
```

- `metrics` 至少要有 `accuracy` 与 `macro_f1`（都取 0~1）。
- `baseline.accuracy` 必须是**你自己算出来的**：把"训练集里最多的品种"当作对所有人的预测，
  在**同一个测试集**上算 accuracy。（判据会核对它是否可信。）
- `figures` 至少两张：一张"看数据"（②）、一张"评估结果"（⑤），每张都要有 `path` 与一句 `takeaway`。
- 不需要和任何"标准答案"的数值一致 —— 达标看的是"是否真的达到上面两条线"。

## 怎么算完成

1. 写一个能跑的方案（推荐做成 Skill 里的一段脚本），能对任意一份同结构 `data.csv`
   产出 `output.json` 与两张图。
2. 在 `cases/case01` 与 `cases/case02`（第二批样本更少、尺子量得有误差）上都达标 ——
   判据对两个 case 各判一次。
3. 把结论与踩过的坑写进 `SKILL.md` 的「实测档案」。

判据全文见 `judge.md`；怎么自测、包内还有什么，见 `README.md`。
