评分细则（**入门实验：三分类，达标判定**）

⚠️ 本任务的模型与特征用法由学生自选，**输出数值不要求等于参考水平**（`expected.json` 里给的是
"参考水平"，不是标准答案）。

**硬性条件已由平台用确定性断言判定**（见 `manifest.json` 的 `assertions`）：字段完整、图说明齐全、
指标在 [0,1]、切分覆盖全部样本、测试集占比 20%~40%、基线报告可信（与参考值相差 ≤0.10）、
**达标线 `accuracy ≥ 0.90` 与 `macro_f1 ≥ 0.85`**、`notes` ≥20 字。
断言未通过的结果**不会交给你判**，你不必重算这些数值。

你只需要判断以下**语义**问题（任一项不成立 → 不通过）：

1. **`figures` 与 `notes` 是否"看图说话"**：两张图的 `takeaway` 要与图的类型相称 ——
   看数据那张要能说出"哪一类分得开、哪两类重叠"；评估那张要能说出"判错了几个、错在哪一类"；
   `notes` 要给出整体判断（比基线好多少、难点在哪）。两张图互相复述、明显是套话、
   或与 `model` / `metrics` 矛盾 → 不通过。
2. **`model` 与 `metrics` 是否自洽**：例如 `model` 写着"逻辑回归"却报告了只有树模型才可能达到的
   完美结果；或 `metrics` 里混进与任务无关的指标（三分类里只给 precision 不给 macro F1）→ 不通过。
3. **是否可疑地过于好**：本数据集很小、也确实容易，`accuracy` 在 0.93~0.97 属于正常；
   但若达到 0.99 以上且 `notes` 没有可核对的解释（例如把测试集拿去调参、或把测试集样本混进训练）
   → 判为可疑 → 不通过。
4. **`baseline` 的定义是否正确**：必须对应"一律猜训练集里最多的那个品种"这类朴素做法。
   若学生把"另一个训练好的模型"当基线（自欺欺人地拉低参照）→ 不通过。

判定口径：
- 键序、缩进、空白、小数位差异不扣分。
- `score` = 上述语义项的达成程度（0~1）；任一项不成立时 score 不超过 0.5。
- rationale 用中文、**一句话（≤60 字）**说清结论；不通过时指出具体是哪一项。
