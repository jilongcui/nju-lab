# 题目包：按花瓣尺寸识别鸢尾花品种（入门 · 三分类）

> 这是本实验的**题目包** —— 一个很简单的真实需求（量花瓣尺寸报品种）、判据、两批数据，
> 外加**一份示范实现**（`reference/`）供你对照学习。

## 这个实验要学什么

1. **从需求出发做选择**：先看清目标（三个品种都要认出来、要比"一律猜最多"好得多），
   再决定用什么模型 —— 而不是拿到一个模型名字往数据上套。
2. **基线（baseline）意识**："我的模型好不好"必须有参照物。本实验的参照物是
   **"一律猜训练集里最多的品种"**（不建模能做到多少）。
3. **分类要看两个数**：`accuracy` 告诉你整体对了多少，`macro F1` 告诉你"每个类别是不是都认得住"——
   只认两个、放弃一个时，前者可能还行，后者会立刻掉下来。
4. **混淆矩阵**：分类任务的"错在哪"要用 3×3 的混淆矩阵看，而不是只知道"错了几个"。
5. **可复现**：固定随机种子、写清切分，别人才能复核你的结论。

## 实验流程（六步）

`task.md` 里写了完整流程（① 看清需求 → ② 看一眼数据并画图 → ③ 定基线 → ④ 训练模型 →
⑤ 评估并画图 → ⑥ 写结论），`reference/scripts/train.py` 是一份**把这六步都走完**的示范 ——
照着走一遍，再换成你自己的做法。

## 包内有什么、怎么用

| 路径 | 是什么 | 建议怎么用 |
|---|---|---|
| `task.md` | 需求 + 三条要求 + 数据字典 + 交付格式 | **动手前先读** |
| `judge.md` | 判据：达标线、会被核对的项 | 交之前读一遍 |
| `reference/` | **示范实现**（逻辑回归 + 两个花瓣特征 + 基线对比） | 先读 `scripts/train.py`，再写自己的 |
| `cases/case01`、`case02` | 两批数据 + 参考水平 `expected.json` | 自测用 |

## 两批数据

| case | 规模 | 特点 | 参考水平（基线 → 参考实现） |
|---|---|---|---|
| case01 | 150 行（三类各 50） | 手工测量较准 | accuracy 0.32 → 0.95（macro F1 0.95） |
| case02 | 120 行（三类各 40）+ 测量误差 | 样本更少、尺子量得有偏差 | accuracy 0.33 → 0.93（macro F1 0.93） |

> `expected.json` 里的数值**不是标准答案**，而是"参考水平"：判据用它核对你的
> `baseline.accuracy` 是否可信、并识别"可疑地过于好"的结果。你可以做得比参考实现更好，
> 只要说清是怎么做到的（本数据集很小，做到 0.97 左右是正常的）。

## 自测方法

CLI 约定：`train.py <case_dir> <output.json>`（`<case_dir>` 里要有 `data.csv`）。

```sh
# 两个 case 都跑一遍，看是否达标（accuracy ≥ 0.90、macro F1 ≥ 0.85）
for c in cases/*/; do python3 <你的skill>/scripts/train.py "$c" /tmp/out.json; done
```

脚本末尾会打印 `[达标] / [未达标]` 与各项数值。判据的其余各项（结构、切分占比、`notes`）
请对照 `judge.md` 自己核一遍。

> 卡住了怎么办：先看 `reference/scripts/train.py` 里对应的那一段。
