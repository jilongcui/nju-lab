# 鸢尾花品种识别 Skill（你的方案）

> **这是入门实验，重点不是"用多强的模型"，而是把一次完整的小分析走完**：
> 看一眼数据 → 定基线 → 训练 → 评估 → 写结论。
> 模型由你自己决定（逻辑回归、决策树、KNN 都行），达标看的是
> "**accuracy ≥ 0.90 且 macro F1 ≥ 0.85** + 能不能用图说清判断"。

## 实验材料（都在题目包 `problem/` 里，领取后工作区就有）

| 材料 | 作用 |
|---|---|
| `task.md` | 业务背景 + 三条要求 + 数据字典 + 交付格式 |
| `judge.md` | 判据：达标线怎么算、哪些项会被核对 |
| `reference/` | 一份**示范实现** —— 先读它，再写你自己的（它不是标准答案） |
| `cases/case01`、`cases/case02` | 两批数据，自测用 |

**实验流程（六步，与 `task.md` 一致 —— 每一步都要走完）**：

| 步 | 做什么 | 落在哪 |
|---|---|---|
| ① 看清需求 | 三个品种都要认；比"一律猜最多"明显更好 | 心里有数 |
| ② **看一眼数据 + 画图** | 两个花瓣特征怎么分布？哪两类重叠？并画出散点图 | `figures/` 里第 1 张图 |
| ③ 定基线 | 不建模能做到多少（一律猜训练集里最多的品种） | 报告的 `baseline` |
| ④ **训练模型** | 选一个能讲清楚的模型训练（不必做多方案对比） | 报告的 `model` / `metrics` |
| ⑤ **评估 + 画图** | 算 accuracy 与 macro F1，画混淆矩阵看错在哪 | `figures/` 里第 2 张图 |
| ⑥ **写结论** | 每张图一句结论 + 整体判断（难点、不足） | 报告的 `figures` / `notes` |

材料配合：`task.md`（需求 + 流程）→ 读 `reference/`（一份**走完这六步**的示范，含它画的两张图与各自结论）→ 回 `scripts/train.py` 走自己的六步 → 两个 case 都跑 → 补全下面的能力边界与实测档案 → 提交。

## 要做的决策（本实验的重点）

1. **用哪些特征**：两个都给，还是只用其中一个？看图说说你的理由。
2. **模型**：为什么是它？逻辑回归和 KNN 的区别是什么？（能讲清楚就够了）
3. **基线**：现有做法是什么？怎么在**同一个测试集**上算它的成绩？
4. **评估**：为什么除了 accuracy 还要看 macro F1？（只认两个品种时会怎样）

## 自测

```sh
for c in cases/*/; do
  python3 scripts/train.py "$c" /tmp/out.json
done
```

> 卡住了怎么办：先看 `reference/scripts/train.py` 里对应的那一段，再回来改自己的实现。
