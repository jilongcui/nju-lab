评分细则（**用你的 Agent 做一个真实应用**）

⚠️ 这一章**不跑自动复验**，评分以人工 rubric 为主。下面五条是语义判据，任一条明显缺失 → 扣分。

1. **需求覆盖**：所选需求（A 或 B）里的每一条都落地了吗？有没有"看起来做了其实没做"
   （例如需求要"异常值提示"，结果只把数据贴了一遍）。
2. **数据与口径**：数据来源与字段含义说清了吗（虚构 / 脱敏 / 公开）？判断规则**写进代码**了吗，
   还是让模型"看着办"？—— 只看模型输出的、每次不一样的，不算。
3. **结果可复核**：结果能不能被第三方一行行核对？有没有表格、出处（数据行 / 指南段落）、计数？
   只给一段"结论"的，不给分。
4. **边界与安全**：该拒答的拒答（"直接说是不是 XX 病"）、该提示复核的提示（异常值），
   不越位下诊断结论。
5. **演示与说明**：3 分钟能不能讲清"给谁用、输入什么、产出什么、边界在哪、哪一步最容易错"。

判定口径：`score` 0~1；任一条明显缺失不超过 0.6。rationale 用中文一句话说清。
