# 评分细则（语义判据）

> 硬性条件由 `manifest.json` 的 `assertions` 判定（逐步快照 / 检索 / 最终表 / 图 / notes）。
> 这里只判**语义**，任一项不成立 → 不通过。

1. **`notes` 是不是自己写的**：要说清「更新 = 旧条目作废 + 新条目顶上」与「遗忘 = 改状态不再命中」的差别，
   并点出至少一条边界（更新已作废条目要跳过 / 遗忘只处理 active / 检索必须过滤状态）。空话 → 不通过。
2. **是否把"更新"写成了删除**：`final.rows` 里必须还能看到被更正的旧条目（`superseded`），
   而不是只剩新条目；少了旧行 → 不通过。
3. **遗忘是否只处理 active**：case02 里 `M02` 原本就是 `superseded`，执行 `forget M02` 后它必须**仍是**
   `superseded`（不能变成 `forgotten`）。
4. **检索是否真的过滤了状态**：case01 第 6 步检索「过敏 + 用药」只能取到 `M03v2`，
   如果还取到 `M02`（已遗忘）或 `M03`（已作废）→ 不通过。
5. **图是否"看图说话"**：`takeaway` 要说出最后一步三种状态各有几条、并解释 superseded 为什么留着；
   与 `final.counts` 矛盾 → 不通过。
