评分细则（**把附件整理成一份能复核的报告 · 容易**）

可机器判定的部分（三类附件的行数、指标表逐行、计数自洽、四节名称与篇幅）已在 `task.md` 里钉死，
由平台用**确定性断言**判定；断言未通过的结果不会交给你判。

你只需要判断以下**语义**问题（任一项不成立 → 不通过）：

1. **`notes` 是否说清"为什么先解析成行"**：只有拆成 `item/value/unit` 才能逐行核对、
   才能判断哪一行超参考区间；把 PDF 原文整段贴进报告做不到这件事。只写"我实现了"→ 不通过。
2. **有没有把"超区间"写成"诊断"**：提示复核可以，写"因此病人是 XX 病"→ 不通过。
3. **是否正视局限**：至少一条真实局限（约定形态的 PDF、图片识别会错、只做字面抽取等）。
   只复述题干 → 不通过。

判定口径：键序/空白/措辞差异不扣分；数值由断言负责；`score` 0~1，任一项不成立不超过 0.5。
