# 评分细则（语义判据）

> 硬性条件由 `manifest.json` 的 `assertions` 判定（Top-K 逐条比对、分数容差、降序、空结果、图与 notes）。
> 这里只判**语义**，任一项不成立 → 不通过。

1. **`notes` 是否是"自己写的"**：要说出向量怎么来的（同义词归一 + 概念计数）、为什么同义改写也能命中、
   为什么 0 分结果要丢掉。空话或照抄模板 → 不通过。
2. **`retrieval` 与 `index` 是否自洽**：`index.dim` 与词表概念数一致、`n_docs` 与 `docs.csv` 行数一致。
3. **图是否"看图说话"**：`takeaway` 要说清三种查询的差别（同词 / 同义 / 不相关），与 `retrieval` 矛盾 → 不通过。
4. **是否手写结果**：如果 `top_k` 的分数与 `notes` 里描述的现象对不上 → 不通过。
