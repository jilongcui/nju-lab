# 参考实现（示范）

> 出题时的示范：一份走完六步的 `scripts/solve.py`。平台不检查这份内容，只要求它在题包里。

## 怎么做

1. 读 `concepts.json` 的 8 个概念与同义词表；
2. `vectorize()`：同义词按长度降序替换成概念，再按概念 `count()` 成 8 维向量；
3. `cosine()`：点积 / 模长乘积；查询向量全 0 时返回 0；
4. 每条查询取分数 > 0 的 Top-3，按「分数降序 + doc_id 升序」排序，分数四舍五入 4 位；
5. `matplotlib` 画三条查询的 top-1 分数柱状图（轴标签英文）；
6. `notes` 说清机制与三种查询的差别。
